## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | F10 |
| 页面名称 | 我的报名 |
| 页面路由 | `/me/enrollments` |
| 所属模块 | 个人中心 |
| 页面类型 | 前台登录页（需雏英身份） |
| 适用角色 | **仅雏英** |
| 页面目的 | 查看本人活动报名列表、线上进度与是否可发起「活动完成心得」申请入口 |
| 前置条件 | 会话有效且角色为雏英；否则跳转 `/login?redirect=/me/enrollments` |
| 终端规格 | PC Web；Chrome 90+ / Edge 90+；**1366×768**+；V1 不做移动端适配 |

### 1.1 与类型一申请的关系

本页展示报名记录；**是否可申请**遵循全站常量：

| 活动形态 | 可申请条件 |
| --- | --- |
| 线上 | 已报名 + 观看进度 **≥ 99%** |
| 线下 | 已报名 + 当前时间 ∈ `[endAt, endAt + 24h]` |

同一活动类型一是否只允许通过一次：`[待决]`，未决前列表侧按「无可再申」隐藏入口或灰显并提示。

## 3. 区域说明与交互

### 3.1 列表列定义

| 列 | 说明 |
| --- | --- |
| 活动标题 | 可点击 → `/activities/:id` |
| 形态 | 线上 / 线下 |
| 时间 | 开始–结束（展示格式本地化） |
| 报名状态 | V1 主要为「已报名」；若后续有取消等再扩展 |
| 进度/窗口 | 线上：进度百分比；线下：是否已结束、申请窗口剩余时间或「已过期」 |
| 操作 | 「申请心得」或不可用原因文案 |

### 3.2 「申请心得」按钮规则

| 条件 | 按钮状态 |
| --- | --- |
| 满足可申请条件且尚无进行中/已通过类型一（按待决规则） | 可点 → `/me/applications/new?type=activity&activityId=` 或等价预填 |
| 线上进度 < 99% | 禁用；旁注「进度需达到 99%」 |
| 线下未结束 | 禁用；旁注「活动结束后 24 小时内可申请」 |
| 线下超过 endAt+24h | 禁用；旁注「申请窗口已关闭」 |
| 已有待审类型一 | 禁用或改为「查看申请」→ 对应 F14 `[待补充]` |
| 已通过且规则禁止再申 | 禁用；旁注「已获得该活动积分」`[待决]` |

### 3.3 加载 / 错误

| 态 | 处理 |
| --- | --- |
| 加载 | 表格骨架屏 |
| 失败 | Toast + 重试 |
| 空 | 见空状态 + CTA 浏览活动 |

## 4. 关键字段与校验

本页无创建表单；筛选为查询参数。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| filter.form | enum | all / online / offline |
| enrollment.activityId | id | 关联活动 |
| enrollment.status | enum | enrolled 等 |
| progress.percent | 0–100 | 仅线上有意义 |
| activity.endAt | datetime | 线下窗口计算基准 |
| canApplyType1 | bool | 服务端计算后下发，前端勿自创阈值 |

## 5. 处理流程

### 5.1 主流程

1. 鉴权通过后拉取本人报名分页列表（含进度与 canApply）。  
2. 用户浏览列表；可点活动进详情。  
3. 满足条件时点「申请心得」进入 F13（预填类型一与活动）。

### 5.2 分支流程

| 分支 | 行为 |
| --- | --- |
| 筛选形态 | 刷新列表，保留分页从第 1 页起 |
| 无可报名 | 引导 `/activities` |
| 从活动详情报名成功后回跳本页 | 列表出现新记录 |

### 5.3 异常流程

| 异常 | 处理 |
| --- | --- |
| 未登录 | `/login?redirect=/me/enrollments` |
| 列表失败 | Toast + 重试 |
| 活动已下架 | 标题旁注「已下架」；申请入口按服务端 canApply |

## 7. 验收要点（AC）

1. **AC-F10-01** 未登录访问跳转 `/login?redirect=/me/enrollments`。  
2. **AC-F10-02** 仅展示当前雏英本人的报名记录。  
3. **AC-F10-03** 线上进度 <99% 时不可发起心得申请；≥99% 且规则允许时可进入 F13。  
4. **AC-F10-04** 线下仅在 endAt 起 24 小时内显示可申请；超时不可申请。  
5. **AC-F10-05** 无报名时展示空状态与「浏览活动」CTA。  
6. **AC-F10-06** 点击活动标题进入对应活动详情页。
