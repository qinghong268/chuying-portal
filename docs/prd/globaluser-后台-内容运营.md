## 3. 区域说明与交互

| 区域 | 说明与交互 |
| --- | --- |
| Tab / 栏目 | 按内容域切换（首页 / 计划介绍）；切换时若编辑未保存，二次确认「放弃未保存修改？」 |
| 区块表格 | PC 表格风格：分页默认 20 条；按排序权重升序 |
| 编辑区 | 失焦校验标题；富文本工具栏含基础段落/加粗/链接；图片上传失败 Toast |
| 存草稿 | 写入草稿状态，前台仍展示上一版已发布内容 |
| 保存并发布 / 发布变更 | 将当前编辑或勾选草稿发布为线上版本；成功 Toast「已发布」 |
| 预览前台 | 新开前台对应页（`/` 或 `/about`）；若支持草稿预览则带 `?preview=1`，实现阶段定协议 `[待补充]` |
| 加载/空/错 | 表格骨架屏；无区块时空态「暂无内容块，请联系研发初始化种子」；接口失败可重试 |
| 权限 | 无 `content`：无权限页；有权限但只读场景 V1 不做，默认可编辑 |

## 4. 关键字段与校验

| 字段 | 必填 | 校验与说明 |
| --- | --- | --- |
| blockKey | 是（系统） | 稳定标识，如 `home_hero`、`home_plan_promo`、`home_company_promo`、`about_body`；运营不可随意改 key |
| title | 是 | 1–80 字 |
| body | 条件 | 富文本；空内容不可「保存并发布」（可存草稿）；公司/计划终稿可先存占位再替换 |
| coverUrl / mediaUrl | 否 | 合法 URL 或上传成功后的路径；视频封面同理 `[待补充：格式限制]` |
| externalLink | 否 | 公司官网等外链；须为 http(s) |
| sortOrder | 是 | 整数；越小越靠前；建议 Hero → 计划宣传 → 公司宣传 |
| status | 是 | `draft` / `published` |
| visible | 是 | 布尔；关闭则前台不渲染该块 |

**素材说明：** `home_plan_promo`、`home_company_promo` 的终稿图文/视频标 **`[待运营提供]`**；V1 须保留可编辑槽位，允许占位发布。

业务边界：课程、活动**列表正文**不在本页维护（活动见 A05/A06）；首页精选活动/课程由业务接口提供，本页仅 CMS `ContentBlock`。

## 5. 主流程 / 分支 / 异常

**主流程**：进入内容运营 → 选 Tab → 点编辑 → 修改标题/正文 → 保存并发布 → 前台对应页可见新内容。

**分支流程**：

1. 仅存草稿：前台仍为旧版；列表状态显示「草稿」。  
2. 关闭可见：已发布也可设不可见，前台隐藏该块。  
3. 多区块同页：按 `sortOrder` 拼接渲染。

**异常流程**：

| 场景 | 系统行为 |
| --- | --- |
| 无 `content` 直链 | 无权限页 |
| 并发覆盖 | 保存时若版本冲突返回提示「内容已被他人更新，请刷新后重试」`[推断：乐观锁，实现可定]` |
| 发布时正文为空 | 字段下错误提示，阻止提交 |
| 上传超限 | Toast 说明大小/格式限制 `[待补充]` 具体阈值 |

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/content/blocks?scope=` | 按栏目列出内容块 |
| GET | `/api/admin/content/blocks/:id` | 块详情（含草稿正文） |
| PUT | `/api/admin/content/blocks/:id` | 保存草稿或更新字段 |
| POST | `/api/admin/content/blocks/:id/publish` | 发布 |
| POST | `/api/admin/content/upload` | 图片上传 |

鉴权：需管理端 Session/JWT + `content` 权限包。

## 7. 验收要点（AC）

1. 仅持有 `content`（或超管）的账号侧栏可见「内容运营」且可打开本页。  
2. 无 `content` 直链 `/admin/content` 展示无权限页，无内容数据泄露。  
3. 编辑后「保存并发布」，前台首页/计划介绍在刷新后展示新文案（同环境）。  
4. 「存草稿」不改变前台已发布内容。  
5. 标题为空或发布时空正文时，提交被拦截并贴字段错误。  
6. 表格具备加载态与失败重试。  
7. 首页栏目下可维护并发布 `home_plan_promo` 与 `home_company_promo`，前台首页对应专区可见更新。
