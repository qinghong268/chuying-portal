# F01：首页 -- 产品需求文档

> 索引：`docs/prd/globaluser.md` · 设计：`docs/superpowers/specs/2026-08-02-chuying-portal-design.md`

## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | F01 |
| 页面名称 | 首页 |
| 页面路由 | `/` |
| 所属模块 | 首页 |
| 页面类型 | 前台浏览页（公开，无需登录） |
| 适用角色 | 访客、雏鹰；管理员/超管可浏览公开内容 |
| 页面目的 | **宣传**雏鹰计划与软通智慧公司，并提供活动/课程精选入口及加入转化；首页不是「活动课表站」，宣传与业务入口并存 |
| 前置条件 | 可访问前台站点；宣传与叙事内容来自 CMS 已发布区块；活动/课程精选来自已发布业务数据 |
| 终端规格 | PC Web；Chrome 90+ / Edge 90+；分辨率 **1366×768** 及以上；V1 **不做**移动端适配 |

### 1.1 首页内容职责（V1.1）

| 职责 | 是否必做 | 说明 |
| --- | --- | --- |
| 雏鹰计划宣传 | **必做** | Hero + 计划宣传专区；详细路径/FAQ 仍可由 F02 承接 |
| 软通智慧公司宣传 | **必做** | 独立「关于软通智慧 / 公司介绍」专区；对外素材、成图、片花等 **后续提供**，PRD 先落结构与 CMS 槽位 |
| 活动 / 课程展现 | **必做（精选）** | 首屏以下可展示有限条精选活动、精选课程；完整列表仍在 `/activities`、`/courses` |
| 加入转化 | **必做** | 主 CTA「加入我们」等 |

**素材约定：** 计划宣传与公司宣传的最终文案、主视觉、视频、证照级 Logo 等标 **`[待运营提供]`**；上线前可用占位图/占位文案，**不得**编造公司业绩数字或未确认荣誉。

### 1.2 首屏硬性约束

| 约束 | 说明 |
| --- | --- |
| 首屏组成 | 品牌名（雏鹰计划）+ 一句价值主张 + 一句短支持文案 + CTA 组 + **一张**主视觉（全宽/全bleed 优先） |
| 禁止入首屏 | 统计卡片/指标条、**完整**活动/课程列表、日程、地址块、多入口促销条、浮动角标/徽章叠层；公司长文案也不挤进首屏 |
| 主 CTA | 「加入我们」→ `/join`；「查看活动」→ `/activities`（可选第三链「了解软通」锚点到公司宣传区） |
| 内容原则 | 宣传叙事优先于列表堆砌；计划细则可「了解更多」→ F02 |

### 2.2 区域尺寸建议

| 区域 | 规格 |
| --- | --- |
| 顶栏 | 高 64px，全宽固定或静态置顶 `[待补充：是否 sticky]` |

## 3. 区域说明与交互

### 3.1 顶栏

| 项 | 说明 |
| --- | --- |
| Logo | 点击回 `/`；当前页「首页」导航高亮 |
| 导航 | 首页｜计划介绍｜活动｜课程｜加入我们；登录后增加「个人中心」 |
| 登录态 | 未登录显示「登录」→ `/login`；已登录显示头像菜单（个人中心 / 退出等，细则见账号文档） |

### 3.2 首屏 Hero

| 项 | 说明 |
| --- | --- |
| 数据来源 | CMS `ContentBlock`（页面键：`home` / 区块键如 `hero`）`[待补充：精确 blockKey 命名]` |
| 展示字段 | 品牌固定文案「雏鹰计划」+ CMS：`headline`、`subcopy`、`heroImageUrl`、主/次 CTA 文案（若运营可配；默认见下） |
| 默认 CTA | 主按钮「加入我们」→ `/join`；次按钮「查看活动」→ `/activities` |
| 交互 | 按钮 hover/focus 可见；点击整页跳转，无弹层 |
| 加载 | Hero 区骨架（标题条 + 按钮占位 + 背景淡入） |
| 空/未发布 | 展示站点默认占位文案与默认 CTA；不得空白整屏崩溃；占位文案标运营可改 `[待补充：默认文案终稿]` |

### 3.3 雏鹰计划宣传专区（区块 A）

| 项 | 说明 |
| --- | --- |
| 目的 | 在首页强化计划价值与培养叙事，不仅依赖活动/课程列表传达计划含义 |
| 数据来源 | CMS，建议 `blockKey`：`home_plan_promo`（及子要点 `home_plan_highlights`）`[待补充：精确命名]` |
| 展示 | 标题、短述、配图/图集位、2～4 条亮点（标题+短描述）；**禁止**未核实的量化业绩条 |
| CTA | 「了解更多」→ `/about`；可复用「加入我们」 |
| 素材未到 | 展示占位文案/占位图，区块结构仍渲染，避免整区消失导致信息架构空洞 |
| 加载/错误 | 区块级骨架；失败可重试；失败时保留占位骨架+跳转 `/about` 的文字链 |

### 3.4 软通智慧公司宣传专区（区块 B）

| 项 | 说明 |
| --- | --- |
| 目的 | 向访客传达主办/背书主体「软通智慧」品牌，与「雏鹰计划」并列宣传 |
| 数据来源 | CMS，建议 `blockKey`：`home_company_promo` |
| 展示字段（逻辑） | `companyName`（默认「软通智慧」）、`headline`、`body`/`richtext`、`mediaUrl`（图或视频封面）、可选外链「官网」`[待运营提供]` |
| 素材约定 | 终稿文案、主视觉、视频、Logo 规范等 **`[待运营提供]`**；未提供前用中性占位，**不编造**营收、排名、客户名单 |
| 锚点 | 建议 DOM id：`#company`，供首屏「了解软通」与页脚链入 |
| 与计划区关系 | 计划区讲「计划是什么」；本区讲「公司是谁 / 为何可信」；二者不得合并成一块导致品牌混淆 |
| 加载/错误 | 同区块 A；公司区失败不影响计划区与精选列表 |

### 3.5 精选活动 / 精选课程（区块 C / D）

| 项 | 说明 |
| --- | --- |
| 目的 | 首页兼顾业务触达：展示少量进行中/即将开始的活动与课程 |
| 数据来源 | 已发布活动/课程接口；排序规则建议「进行中优先 → 开始时间近」`[待补充]` |
| 数量 | 各建议最多 **3** 条；超出不在本页展开，用「查看全部」进入列表页 |
| 卡片字段 | 标题、形态/标签、时间摘要、封面缩略图（可无图）；点击进详情 |
| 空态 | 无精选时隐藏该区块或展示「暂无进行中的活动/课程」+ 链到列表页 |
| 禁止 | 在首页嵌入可滚动的完整活动/课程库、复杂筛选器 |

### 3.6 页脚

计划简介摘要、锚点至公司宣传区或外链（若运营配置）、主导航链接、© SoftTong / 软通智慧。链接失效时隐藏该项或跳转安全页 `[待补充]`。

## 4. 关键字段与校验

本页**无用户输入表单**。展示字段由 CMS 发布内容决定：

| 字段（逻辑） | 类型 | 校验/约束 | 说明 |
| --- | --- | --- | --- |
| headline | 文本 | 非空才替换默认标题；长度上限 `[待补充]` | 首屏主标题 |
| subcopy | 文本 | 可空；建议 ≤80 字 | 支持句 |
| heroImageUrl | URL | 合法 URL；加载失败用默认底图 | 主视觉 |
| planPromo.* | 文本/富文本/媒体 | 计划宣传专区；素材 `[待运营提供]` | 区块 A |
| companyPromo.* | 文本/富文本/媒体 | 公司宣传专区；素材 `[待运营提供]` | 区块 B |
| highlightItems[] | 数组 | 建议 2～4 条；超限截断展示 | 计划亮点（可挂在 A 区） |
| ctaPrimaryLabel / Href | 文本/路径 | 默认「加入我们」`/join` | 可运营覆盖 |
| ctaSecondaryLabel / Href | 文本/路径 | 默认「查看活动」`/activities` | 可运营覆盖 |
| featuredActivities[] | 业务列表 | 服务端截断 ≤3 | 区块 C，非 CMS 长文 |
| featuredCourses[] | 业务列表 | 服务端截断 ≤3 | 区块 D，非 CMS 长文 |

## 5. 处理流程

### 5.1 主流程

1. 用户打开 `/`。  
2. 系统并行拉取：首页已发布 CMS（Hero + 计划宣传 + 公司宣传）、精选活动、精选课程、公共布局。  
3. 按顺序渲染：顶栏 → Hero → 计划宣传 → 公司宣传 → 精选活动 → 精选课程 → 页脚。  
4. 用户可加入、看活动/课程，或阅读计划/公司宣传后进入介绍页。

### 5.2 分支流程

| 分支 | 行为 |
| --- | --- |
| 点击「了解更多」/计划介绍导航 | 进入 `/about` |
| 点击「了解软通」或页脚公司链 | 滚动至 `#company`（或打开运营配置的外链） |
| 点击精选活动/课程卡片 | 进入对应详情 |
| 点击「查看全部」活动/课程 | 进入 `/activities` 或 `/courses` |
| 已登录雏鹰点「个人中心」 | 进入 `/me` |
| 未登录点「登录」 | 进入 `/login`（可选带 `redirect=/`） |

### 5.3 异常流程

| 异常 | 处理 |
| --- | --- |
| CMS 接口失败 | Toast + 重试；Hero 使用本地默认占位，保证双 CTA 仍可用 |
| 图片加载失败 | 降级纯色/默认图，文案与 CTA 不受影响 |
| 未发布首页内容 | 默认占位叙事 + 默认 CTA（不展示后台草稿） |

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/content/home` 或 `/api/content-blocks?page=home` | 拉取首页已发布区块（含计划宣传、公司宣传） |

## 7. 验收要点（AC）

1. **AC-F01-01** 在 1366×768 视口下，首屏可见品牌「雏鹰计划」、价值主张、支持句、以及「加入我们」「查看活动」两个 CTA，且**不出现**统计卡片或完整活动/课程列表。  
2. **AC-F01-02** 首屏以下存在**雏鹰计划宣传专区**与**软通智慧公司宣传专区**（结构位必现；真实素材未到时允许占位）。  
3. **AC-F01-03** 计划宣传与公司宣传为两块独立区域，文案/媒体槽位可分别由 CMS 配置。  
4. **AC-F01-04** 存在精选活动、精选课程模块（有数据时各 ≤3 条），并提供进入完整列表的入口；无数据时不白屏。  
5. **AC-F01-05** 点击「加入我们」→ `/join`；「查看活动」→ `/activities`；精选卡片进详情。  
6. **AC-F01-06** 未登录与已登录均可完整浏览；顶栏登录态正确。  
7. **AC-F01-07** CMS 或精选接口失败时，页面不白屏；已成功区块保留；默认 CTA 仍可用。  
8. **AC-F01-08** 仅展示已发布 CMS 与已发布活动/课程；草稿不可见。  
9. **AC-F01-09** 页面不展示未核实的公司业绩/排名等编造数据；素材位标注可由运营替换。
