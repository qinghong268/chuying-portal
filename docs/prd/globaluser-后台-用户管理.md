## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A11 |
| 页面名称 | 用户管理 |
| 页面路由 | `/admin/users` |
| 权限包 | `user` |
| 适用角色 | 已授予 `user` 的管理员；超级管理员 |
| 页面目的 | 查看与管理雏鹰及管理员账号的基础信息与账号状态（启用/停用等） |
| 页面类型 | 后台表格列表 + 状态操作 |
| 前置条件 | 已登录且持有 `user` |

### 1.1 范围边界

| 支持（V1） | 不支持（V1） |
| --- | --- |
| 列表/搜索/按角色与状态筛选 | 在本页配置权限包（见 A13） |
| 查看账号基础资料 | 积分调账、删除用户物理数据 |
| 启用 / 停用账号 | 批量导入导出（P2，`[待补充]`） |
| 区分雏鹰 / 管理员 / 超级管理员展示 | 修改超管身份（禁止普通管理员提权） |

## 3. 区域说明与交互

| 区域 | 规则 |
| --- | --- |
| Tab | 雏鹰 / 管理员（含超管）/ 全部；默认「雏鹰」 |
| 状态 | 正常（启用）/ 停用；筛选与列徽章一致 |
| 关键词 | 姓名、邮箱、手机号等已有标识字段模糊搜 |
| 停用 | 二次确认；成功后前台/后台登录拒绝或会话失效（实现选 Session 踢出） |
| 启用 | 行内「启用」，可轻确认 |
| 查看授权摘要 | 仅管理员行展示；只读列出已授予权限包名称；完整授权在 A13（超管） |
| 自我保护 | 不可停用**自己**的账号；按钮置灰 + Tooltip |
| 超管保护 | 非超管不可停用超级管理员；超管停用另一超管规则：`[待核实]` 至少保留 1 名可用超管 |
| 加载/空/错 | 骨架屏；空态文案；错误可重试 |

## 4. 关键字段与校验

| 字段/操作 | 规则 |
| --- | --- |
| 角色 | 只读展示：访客不在本表；雏鹰 / 管理员 / 超级管理员 |
| 状态切换 | 仅 `active` ↔ `disabled`（命名以实现为准） |
| 资料编辑 | V1 不做资料改档表单；若演示需要可只读抽屉展示注册/加入信息 |

## 5. 主流程 / 分支 / 异常

### 5.1 主流程：停用雏鹰

1. 管理员打开用户管理 → Tab「雏鹰」。  
2. 搜索目标用户 →「停用」→ 确认。  
3. 系统置 `disabled`；该用户无法再登录前台受保护能力；Toast「已停用」。

### 5.2 分支

| 分支 | 行为 |
| --- | --- |
| 重新启用 | 状态恢复正常，可登录 |
| 查看管理员授权摘要 | 弹层展示权限包列表（只读） |
| 筛选停用账号 | 状态=停用时仅列出停用用户 |

### 5.3 异常

| 场景 | 处理 |
| --- | --- |
| 停用自己 | 前端禁用 + 接口 400 |
| 停用最后一名超管 | 拒绝并 Toast 说明 |
| 无权限 | 无权限页 |

## 7. 验收要点（AC）

1. 持有 `user` 可访问；无权限直链无权限页。  
2. 可按角色 Tab 与状态、关键词筛选列表。  
3. 停用需二次确认；停用后该账号不可正常登录使用（按角色端）。  
4. 不能停用自己；保护「至少一名可用超管」规则生效（若实现）。  
5. 管理员行可查看权限包摘要，但本页不能改授权。  
6. 空/错/加载态符合全局后台规范。
