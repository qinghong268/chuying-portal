## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A13 |
| 页面名称 | 权限管理 |
| 页面路由 | `/admin/permissions` |
| 权限包 | `permission`（**仅超级管理员**持有；普通管理员即使直链也无权限） |
| 适用角色 | 超级管理员 |
| 页面目的 | 查看 V1 权限包定义，并为管理员账号授予/回收权限包 |
| 页面类型 | 后台配置（权限包只读说明 + 管理员授权编辑） |
| 前置条件 | 当前登录角色为超级管理员 |

### 1.1 V1 权限包（全部上线，code 固定）

| code | 名称 | 说明 |
| --- | --- | --- |
| `content` | 内容运营 | CMS 编辑与发布 |
| `join_review` | 加入审核 | 加入申请通过/驳回 |
| `activity` | 活动管理 | 活动 CRUD、报名名单、线上进度 |
| `point_type` | 积分类型 | 模板启用/停用与分值配置 |
| `point_review` | 积分审批 | 申请队列审批 |
| `user` | 用户管理 | 雏英与管理员账号状态 |
| `dashboard` | 数据看板 | 关键指标总览 |
| `permission` | 权限管理 | 仅超管：本页能力；**不可授予普通管理员** |

无权限包：对应侧栏菜单不展示；直链进入无权限页。

## 3. 区域说明与交互

| 区域 | 规则 |
| --- | --- |
| 入口 | 仅超管侧栏显示「权限管理」；管理员直链 → 无权限页 |
| 管理员授权 Tab | 列出角色为管理员（及可选展示超管只读行）的账号 |
| 编辑授权 | 多选权限包并保存；立即影响侧栏与接口鉴权 |
| `permission` 勾选 | UI **禁用**；接口拒绝授予普通管理员 |
| 超管行 | 展示「全部权限」只读，无「编辑授权」或编辑无效 |
| 添加管理员 | V1 演示：将已有用户提升为管理员并初始化空权限包，或从种子账号选人 `[待核实]` 与登录方案对齐 |
| 停用入口 | 可链到 A11 用户管理处理停用，或本页提供停用（二选一；推荐跳转 A11 避免双入口） |
| 权限包说明 Tab | 只读，不支持自定义新建权限包 code（V1 固定八包） |
| 加载/空/错 | 骨架屏；无管理员时引导「添加管理员」；错误可重试 |

## 4. 关键字段与校验

| 字段 | 规则 |
| --- | --- |
| 权限包多选 | 至少允许保存空集（该管理员登录后台仅见控制台/公共项，无业务菜单）`[待核实]`：空集是否允许登录 `/admin` — 暂定允许进控制台 |
| `permission` | 不可授予非超管 |
| 保存 | 全量覆盖该用户的 `AdminGrant` 列表 |

## 5. 主流程 / 分支 / 异常

### 5.1 主流程：为管理员授权

1. 超管进入 `/admin/permissions`。  
2. 在目标管理员行点「编辑授权」。  
3. 勾选 `content`、`point_review` 等 →「保存」。  
4. 系统更新 `AdminGrant`；Toast「授权已更新」。  
5. 该管理员重新进入或刷新后，侧栏按新权限包显隐。

### 5.2 分支

| 分支 | 行为 |
| --- | --- |
| 回收全部业务包 | 保存空集；管理员无法进业务页 |
| 查看权限包说明 | 只读对照表，便于授权前查阅 |
| 添加管理员 | 创建/提升账号后出现在列表，默认无业务包 |

### 5.3 异常

| 场景 | 处理 |
| --- | --- |
| 非超管访问 | 无权限页；API 403 |
| 尝试授予 `permission` | 前端禁用 + API 400 |
| 编辑自己的超管授权 | 不允许降级/乱改超管包；超管身份不走本抽屉 |
| 并发保存 | 后写覆盖或提示刷新 |

## 6. 接口依赖摘要

| 意图 | 方法 | 路径（示意） |
| --- | --- | --- |
| 权限包目录 | GET | `/api/admin/permission-packages` |
| 管理员及授权列表 | GET | `/api/admin/admin-grants` |
| 更新某管理员授权 | PUT | `/api/admin/admin-grants/:userId` body: `{ packages: string[] }` |
| 添加管理员（可选） | POST | `/api/admin/admins` |

鉴权：上述写接口仅超管；校验 `packages` 不得包含对非超管的 `permission`。

---

## 7. 验收要点（AC）

1. 仅超级管理员可打开本页；普通管理员侧栏无入口，直链为无权限页。  
2. 八个权限包 code 与总览一致且说明 Tab 只读可见。  
3. 可为管理员授予/回收除 `permission` 外的权限包；保存后该账号菜单与直链鉴权立即一致。  
4. `permission` 不可授予普通管理员（UI + API）。  
5. 超管账号不通过本页被降权；展示为全部权限只读。  
6. 保存成功有 Toast；失败可重试；空/错/加载态符合规范。
