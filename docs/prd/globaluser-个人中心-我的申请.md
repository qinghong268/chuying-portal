## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | F11 |
| 页面名称 | 我的申请 |
| 页面路由 | `/me/applications` |
| 所属模块 | 个人中心 |
| 页面类型 | 前台登录页（需雏英身份） |
| 适用角色 | **仅雏英** |
| 页面目的 | 查看本人积分申请列表（类型一/二）、状态与驳回摘要，并进入详情或发起新申请 |
| 前置条件 | 会话有效且角色为雏英；否则跳转 `/login?redirect=/me/applications` |
| 终端规格 | PC Web；Chrome 90+ / Edge 90+；**1366×768**+；V1 不做移动端适配 |

### 1.1 状态与再提规则

| 状态 | 说明 |
| --- | --- |
| 待审批 | 已提交，等待管理员审批 |
| 已通过 | 已入账；展示授予分值 |
| 已驳回 | 展示驳回原因摘要；**再提预留为「新单」**（修改后重新提交生成新申请，不复活原单） |

## 3. 区域说明与交互

### 3.1 列表字段

| 列 | 说明 |
| --- | --- |
| 申请编号 | 业务可读 ID 或短码 |
| 类型 | 类型一「活动完成心得」或类型二模板名称（如比赛获奖） |
| 摘要 | 类型一显示活动标题；类型二显示「具体事项」截断 |
| 提交时间 | 本地时区格式化 |
| 状态 | 待审批 / 已通过 / 已驳回（带色点或标签） |
| 分值 | 通过后显示实际授予分；未通过显示「—」 |
| 操作 | 「详情」；已驳回额外「再申请」（新单） |

### 3.2 交互

| 操作 | 行为 |
| --- | --- |
| 详情 | → `/me/applications/:id`（F14） |
| 发起积分申请 | → `/me/applications/new`（F13） |
| 再申请 | → F13，预留带 `fromRejectedId=` 或仅进入空白新单并提示「将创建新申请」；**不得修改原驳回单** |
| 行点击 | 等同详情（可选） |
| 筛选/搜索 | 防抖后刷新列表 |

### 3.3 加载 / 错误

骨架屏；失败 Toast + 重试；空状态见上。

## 4. 关键字段与校验

| 查询字段 | 类型 | 说明 |
| --- | --- | --- |
| status | enum | all / pending / approved / rejected |
| type | enum | all / activity_reflection / template（或按 templateCode） |
| q | string | 可选，匹配事项/活动名；长度上限 `[待补充]` |
| page / pageSize | int | 分页 |

无写表单。

## 5. 处理流程

### 5.1 主流程

1. 鉴权 → 拉取申请分页列表。  
2. 用户按状态/类型筛选。  
3. 进入详情查看完整内容与审批结果；或发起新申请。

### 5.2 分支流程

| 分支 | 行为 |
| --- | --- |
| 已驳回 · 再申请 | 创建**新单**路径进入 F13；原单保持已驳回只读 |
| 从概览「查看申请」带 status=pending | 默认筛待审批 `[待补充]` |

### 5.3 异常流程

| 异常 | 处理 |
| --- | --- |
| 未登录 | `/login?redirect=/me/applications` |
| 列表失败 | Toast + 重试 |
| 详情 ID 不属于本人 | 详情页处理（见 F14） |

## 7. 验收要点（AC）

1. **AC-F11-01** 未登录访问跳转 `/login?redirect=/me/applications`。  
2. **AC-F11-02** 列表仅含当前用户申请；含类型一与类型二。  
3. **AC-F11-03** 状态筛选「待审批 / 已通过 / 已驳回」结果正确。  
4. **AC-F11-04** 「详情」进入 `/me/applications/:id`。  
5. **AC-F11-05** 已驳回「再申请」进入发起页且语义为**新单**，原驳回记录仍在列表。  
6. **AC-F11-06** 空列表展示发起申请 CTA。
