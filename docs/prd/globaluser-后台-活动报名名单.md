## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A07 |
| 页面名称 | 活动报名名单（含线上进度查看） |
| 页面路由 | `/admin/activities/:id/enrollments` |
| 页面类型 | 管理后台列表页（PC 表格） |
| 适用角色 | 管理员、超级管理员 |
| 所需权限包 | `activity` |
| 页面目的 | 查看某活动全部报名记录；对**线上活动**展示每位报名者的观看进度（`WatchProgress`），支撑运营核查是否达到心得申请门槛（≥99%） |
| 前置条件 | 持有 `activity`；活动 ID 存在 |

进度常量（只读展示/筛选用）：`WATCH_PROGRESS_THRESHOLD = 99`（总览 §5.4 / 设计规格 §5）。

## 3. 区域说明与交互

| 区域 | 说明与交互 |
| --- | --- |
| 活动摘要 | 展示标题、形态、开始/结束、报名截止（线上）、目标积分、报名总数 |
| 表格 | PC 后台表格；报名时间倒序默认 |
| 进度列 | 仅 `form=online`：显示 0–100 整数百分比；空进度显示 0 或「未上报」 |
| 达门槛 | percent ≥ 99 显示「是」（绿），否则「否」 |
| 进度筛选 | 仅线上：全部 / 未达 99% / 已达 99% |
| 刷新（行） | 可选：重新拉取该用户进度；无则依赖整表刷新按钮 |
| 线下列集 | 隐藏进度相关列与筛选；可增加「签到状态」列标 `[待补充]`（V1 可不做签到） |
| 导出 | 若首期不做，隐藏按钮；做则导出当前筛选结果 |
| 加载/空/错 | 骨架屏；「暂无报名」；失败可重试 |
| 权限 | 无 `activity` → 无权限页 |

本页**不审批积分**（积分审批见 A09/A10）；不在此手动改进度（防篡改）。若运营纠错需求出现，另立调账/校正流程。

## 4. 关键字段与校验

| 字段 | 说明 |
| --- | --- |
| enrollmentId | 报名记录 ID |
| userName / contact | 雏英展示名与联系方式（脱敏） |
| enrolledAt | 报名成功时间 |
| watchPercent | 线上：0–100；来自 `WatchProgress` |
| thresholdMet | 计算字段：`watchPercent >= 99` |
| activity.form / startAt / endAt / enrollDeadline / targetPoints | 页头摘要 |

筛选：关键词 trim；进度筛选项仅线上有效。

---

## 5. 主流程 / 分支 / 异常

**主流程**：活动列表点「报名名单」→ 查看报名者 →（线上）核对进度是否 ≥99%。

**分支流程**：按未达门槛筛选督促学习；返回活动列表或进入活动编辑。

**异常流程**：

| 场景 | 系统行为 |
| --- | --- |
| 活动不存在 | 提示并回 `/admin/activities` |
| 无权限 | 无权限页 |
| 进度服务不可用 | 名单仍展示，进度列显示「—」并 Toast「进度暂不可用」 |

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/activities/:id` | 活动摘要（形态、时间、目标积分等） |
| GET | `/api/admin/activities/:id/enrollments` | 报名分页；线上响应附带 `watchPercent` |
| GET | `/api/admin/activities/:id/enrollments/:enrollmentId/progress` | 可选：单行刷新进度 |
| GET | `/api/admin/activities/:id/enrollments/export` | 可选：导出 |

---

## 7. 验收要点（AC）

1. 从 A05 进入本页，页头活动信息与编辑页一致（形态、时间、目标积分）。  
2. 线上活动展示进度百分比与是否达 99% 门槛，筛选「已达 99%」结果正确。  
3. 线下活动不展示进度列/进度筛选，仍展示报名名单。  
4. 无报名时有空状态；无 `activity` 直链为无权限页。  
5. 本页无法直接改进度或发放积分（只读运营核查）。
