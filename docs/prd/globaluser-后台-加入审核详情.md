## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A04 |
| 页面名称 | 加入审核详情 |
| 页面路由 | `/admin/join/:id` |
| 页面类型 | 管理后台详情 + 审核操作页 |
| 适用角色 | 管理员、超级管理员 |
| 所需权限包 | `join_review` |

| 前置条件 | 持有 `join_review`；申请记录存在 |

## 3. 区域说明与交互

| 区域 | 说明与交互 |
| --- | --- |
| 申请人信息 | 只读；敏感联系方式可脱敏，审核人可见完整值（实现可选「点击显示」） |
| 申请说明 | 只读多行文本 |
| 通过 | 二次确认 → 成功后状态变已通过，隐藏操作按钮，写审核记录；Toast「已通过」 |
| 驳回 | 打开弹窗；原因必填（建议 5–200 字）→ 确认后状态已驳回；Toast「已驳回」 |
| 已审状态 | 仅展示审核记录与返回；不可再次通过/驳回（V1 不支持改判；若需改判标 `[待补充]`） |
| 加载/错 | 详情骨架屏；404「申请不存在」；403 无权限页 |

## 4. 关键字段与校验

| 字段 | 来源 | 规则 |
| --- | --- | --- |
| id | 路由 | 存在且当前账号有权查看 |
| name / mobile / email / org | 申请单 | 只读展示 |
| motivation / statement | 申请单 | 只读；可空显示「未填写」 |
| status | 申请单 | pending / approved / rejected |
| rejectReason | 审核写入 | 驳回时必填；trim 后长度 ≥5 且 ≤200；通过时为空 |
| reviewedBy / reviewedAt | 系统 | 审核成功后写入 |

---

## 5. 主流程 / 分支 / 异常

**主流程（通过）**：打开详情 → 核对信息 → 点通过 → 确认 → 状态已通过 → 申请人具备雏鹰能力（与账号体系对接）。

**主流程（驳回）**：打开详情 → 点驳回 → 填写原因 → 确认驳回 → 状态已驳回，原因落库可追溯。

**分支流程**：从列表带筛选返回时保留列表 query（实现可用浏览器返回或「返回列表」带 state）。

**异常流程**：

| 场景 | 系统行为 |
| --- | --- |
| 无 `join_review` | 无权限页 |
| 重复审核（并发已被他人审完） | 提示「该申请已处理，请刷新」并刷新详情 |
| 驳回原因为空或过短 | 「确认驳回」禁用或提交失败贴错误 |
| 通过失败（账号冲突等） | Toast 明确原因，状态保持待审核 |

---

## 7. 验收要点（AC）

1. 待审核单可执行通过与驳回；已通过/已驳回不再出现操作按钮。  
2. 驳回时不填原因或不足 5 字无法提交。  
3. 通过后申请人按设计具备雏鹰身份（可用演示账号链路验收）。  
4. 驳回原因、审核人、时间在详情可查。  
5. 无 `join_review` 直链本页为无权限页。  
6. 并发重复审核有明确提示，不产生双次状态写乱。
