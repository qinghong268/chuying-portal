## 4. 关键字段与校验

本页**无用户输入表单**。逻辑展示字段：

| 字段（逻辑） | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| pageTitle | 文本 | 已发布时非空；否则用默认「计划介绍」 | 页头 |
| lead | 文本 | 可空 | 导语 |
| sections[] | 数组 | 每项含 `key` / `title` / `bodyHtml` / `mediaUrl?` | 定位、路径、亮点等 |
| faq[] | 数组 | 每项 `question` / `answerHtml`；可空数组则隐藏 | FAQ |
| status | 枚举 | 仅 `published` 对前台可见 | 与后台内容运营一致 |

富文本需防 XSS（前端按受信 HTML 消毒策略渲染）`[待补充：消毒库选型]`。

## 5. 处理流程

### 5.1 主流程

1. 用户打开 `/about`（或从首页「了解更多」进入）。  
2. 系统请求已发布介绍内容。  
3. 按区块渲染；用户阅读并可展开 FAQ。  
4. 用户点击「加入我们」进入申请页，或经导航前往活动/课程。

### 5.2 分支流程

| 分支 | 行为 |
| --- | --- |
| 带 hash 进入 | 若支持锚点，滚动至对应区块 |
| 从顶栏其他栏目离开 | 正常路由跳转 |
| 内容仅部分区块发布 | 只渲染已发布区块，跳过空区块 |

### 5.3 异常流程

| 异常 | 处理 |
| --- | --- |
| 接口失败 | Toast + 重试；空状态区提示加载失败 |
| 无已发布内容 | 空状态 + 返回首页 |
| 富文本图片失败 | 单图破图占位，不影响其余段落 |

## 7. 验收要点（AC）

1. **AC-F02-01** 路由 `/about` 在未登录下可访问；「计划介绍」导航高亮。  
2. **AC-F02-02** 仅展示已发布 CMS 内容；草稿不可见。  
3. **AC-F02-03** 有 FAQ 时可展开/收起；无 FAQ 时不显示空 FAQ 区。  
4. **AC-F02-04** 「加入我们」→ `/join`；「查看活动」→ `/activities`。  
5. **AC-F02-05** 无内容时出现空状态与返回首页入口；接口失败可重试。  
6. **AC-F02-06** 1366×768 下长文可滚动完整阅读，无横向撑破。
