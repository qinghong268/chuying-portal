## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A08 |
| 页面名称 | 积分类型管理 |
| 页面路由 | `/admin/point-types` |
| 权限包 | `point_type`（无权限：侧栏不展示；直链进无权限页） |
| 适用角色 | 已授予 `point_type` 的管理员；超级管理员 |
| 页面目的 | 维护类型二专项积分的预置模板：启用/停用、默认分值与展示名称，供雏英发起申请时选择 |
| 页面类型 | 后台配置列表 + 行内/抽屉编辑 |
| 前置条件 | 已以管理员/超管身份登录，且账号持有 `point_type` |

### 1.1 业务背景

类型二（专项/比赛等）申请必须先选择管理员维护的模板。V1 系统预置五条模板，运营侧可调整默认分值与启用状态，不可随意新增/删除模板 code（保证前后台与流水口径稳定）。

### 1.2 V1 预置模板（硬编码种子，不可改 code）

| code | 默认名称 | 说明 |
| --- | --- | --- |
| `contest_award` | 比赛获奖 | 竞赛、hackathon 等获奖加分 |
| `speech` | 分享宣讲 | 内部分享、对外宣讲 |
| `project_contrib` | 项目贡献 | 项目交付/关键贡献 |
| `honor` | 荣誉表彰 | 组织表彰类 |
| `other_special` | 其他专项 | 兜底专项 |

规则（与设计规格一致）：

- 模板可配置：默认分值、是否启用、展示名称（可选改中文名）。  
- V1：**申请人不可改申请分值**；审批人可在审批详情改最终分值。  
- 停用后：前台发起申请时不可再选该模板；历史申请仍按提交时模板展示。

## 3. 区域说明与交互

| 区域 | 规则 |
| --- | --- |
| 列表 | 默认展示全部 5 条预置模板；按更新时间倒序或按固定 code 序（实现任选，文档默认 **固定 code 序**） |
| 筛选·状态 | 全部 / 启用 / 停用；即时过滤 |
| 搜索 | 匹配展示名称或 code，300ms 防抖 |
| 编辑 | 打开抽屉；保存成功 Toast「已保存」，关闭抽屉并刷新行 |
| 启用/停用 | 行内快捷操作；停用需二次确认：「停用后雏英将无法选择该模板发起新申请，确认停用？」 |
| 无「新增/删除」 | V1 不提供新增模板、删除模板入口 |
| 加载态 | 表格骨架屏 5 行 |
| 空状态 | 筛选无结果：「无匹配模板」+「清空筛选」；种子缺失属系统异常，展示错误+重试 |
| 错误态 | Toast + 列表区「加载失败，请重试」 |
| 权限 | 无 `point_type` 直链 → 无权限页 |

## 4. 关键字段与校验

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| code | — | 只读；仅允许上表五值 |
| 展示名称 | 是 | 1–30 字；不可与其它模板重名 `[待核实是否强制唯一]`；暂定允许重名但提示 |
| 默认分值 | 是 | 正整数；范围建议 1–9999；不可为 0 或负数 |
| 启用状态 | 是 | boolean |
| 说明 | 否 | ≤200 字，仅后台可见 |

## 5. 主流程 / 分支 / 异常

### 5.1 主流程：调整默认分值并启用

1. 管理员进入 `/admin/point-types`。  
2. 系统拉取模板列表并渲染。  
3. 管理员点击「编辑」→ 修改默认分值/名称 →「保存」。  
4. 系统校验通过后持久化；Toast 成功；列表刷新。  
5. 前台发起类型二申请时，仅展示「启用」模板，默认分值取最新配置。

### 5.2 分支

| 分支 | 行为 |
| --- | --- |
| 停用模板 | 二次确认 → 状态改为停用 → 前台下拉不可见 |
| 重新启用 | 一行操作「启用」→ 立即生效，无需确认（可加轻确认，P2） |
| 仅改名称 | 不影响历史申请展示字段（历史存快照或展示提交时名称）`[待核实]`：实现建议申请单冗余 `templateName` |

### 5.3 异常

| 场景 | 处理 |
| --- | --- |
| 保存校验失败 | 字段下红字，不关闭抽屉 |
| 并发覆盖 | 后写胜出或 409；Toast「保存失败，请刷新后重试」 |
| 无权限 | 无权限页；接口 403 |

## 6. 接口依赖摘要

| 意图 | 方法 | 路径（示意） |
| --- | --- | --- |
| 列表模板 | GET | `/api/admin/point-types` |
| 更新模板 | PATCH | `/api/admin/point-types/:code` |

请求/响应字段摘要：`code`, `name`, `defaultPoints`, `enabled`, `remark`, `updatedAt`。

## 7. 验收要点（AC）

1. 持有 `point_type` 的管理员可打开本页；无权限直链看到无权限页，侧栏无菜单。  
2. 列表固定可见五条 code：`contest_award` / `speech` / `project_contrib` / `honor` / `other_special`，**无新增按钮**。  
3. 可修改展示名称与默认分值；非法分值（空、非正整数）无法保存。  
4. 停用后前台类型二申请不可再选该模板；启用后可选。  
5. 停用操作有二次确认；保存/启停成功有 Toast。  
6. 加载失败可重试；骨架屏符合全局规范。
