## 1. 系统概述

雏英计划宣传官网是面向 SoftTong「雏英计划」的 **PC Web 全栈系统**：访客在前台首页同时看到**雏英计划宣传**、**软通智慧公司宣传**以及活动/课程精选入口；**雏英**完成报名与积分申请；**管理员 / 超级管理员**在独立后台完成内容（含宣传素材槽位）、审核、活动、积分与权限运营。宣传终稿素材由运营后续提供，文档中标 `[待运营提供]`。

**产品形态：** 同一站点双端入口——前台 `/`、后台 `/admin`  
**演示登录：** 一键切换雏英 / 管理员 / 超级管理员  
**首期语言：** 简体中文  

**终端规格：** PC Web；Chrome 90+ / Edge 90+；分辨率 **1366×768** 及以上

## 2. 用户角色体系

| 角色 | 使用端 | 权限范围 |
| --- | --- | --- |
| 访客 | 前台 | 只读浏览；可提交加入申请 |
| 雏英 | 前台 | 报名活动、提交积分申请、查看个人中心 |
| 管理员 | 后台 | 按已授予的权限包操作 |
| 超级管理员 | 后台 | 全部权限包 + 权限管理 |

### 2.1 后台权限包（V1 全部上线）

| 权限包 code | 名称 | 说明 |
| --- | --- | --- |
| `content` | 内容运营 | CMS 编辑与发布 |
| `join_review` | 加入审核 | 加入申请通过/驳回 |
| `activity` | 活动管理 | 活动 CRUD、报名名单、线上进度 |
| `point_type` | 积分类型 | 模板启用/停用与分值配置 |
| `point_review` | 积分审批 | 申请队列审批 |
| `user` | 用户管理 | 雏英与管理员账号状态 |
| `dashboard` | 数据看板 | 关键指标总览 |
| `permission` | 权限管理 | 仅超管：权限包与管理员授权 |

无权限包：侧栏不展示对应菜单；直链访问展示「无权限」页。

## 5. 全局交互规范

### 5.1 前台布局框架

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏 (64px)：Logo「雏英计划」 | 导航 | [登录/头像▾]        │
├──────────────────────────────────────────────────────────┤
│                                                          │
│                  页面主内容（全宽或 max 1200px）            │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ 页脚：计划简介摘要 | 链接 | © SoftTong                    │

```

前台主导航：首页｜计划介绍｜活动｜课程｜加入我们；登录后增加「个人中心」。  
首页信息优先级：**计划宣传 → 公司宣传 → 精选活动/课程**（完整列表仍在活动/课程频道）。

### 5.4 通用交互规则

| 规则 | 说明 |
| --- | --- |
| 加载态 | 列表/详情异步加载用骨架屏 |
| 空状态 | 插画或简洁文案 + 引导 CTA |
| 错误态 | Toast + 可重试 |
| 表单 | 失焦校验 + 提交全量校验；错误贴字段下方 |
| 二次确认 | 驳回、下架、删除、停用等 |
| Toast | 成功/失败右上角，约 3 秒 |
| 权限 | 后台无权限菜单隐藏；直链无权限页 |

### 5.5 核心业务常量（全站一致）

| 常量 | 值 | 说明 |
| --- | --- | --- |
| 线上观看进度阈值 | **99%** | ≥99% 才可发起「活动完成心得」申请（线上内容本质为视频课程） |
| 线下申请窗口 | **结束时间 + 24 小时** | 活动结束后 24h 内可申请 |
| 心得字数 | **300–1000 字** | 类型一必填；按「字符长度」计 |
| 类型二模板 | contest_award / speech / project_contrib / honor / other_special | 预置，可启用停用 |

**线上/线下定位区分（V1.3）**：线上内容（视频课程类）归入「课程」频道，完成判定仅需观看进度≥99%即可提交心得，不要求活动结束；线下内容（集中实践/工作坊类）归入「活动」频道，须在活动结束后 24h 窗口内申请。此区分使雏英可按内容形态快速定位。

### 5.6 积分申请类型

| 类型 | 名称 | 表单要点 |
| --- | --- | --- |
| 类型一 | 活动/课程完成心得 | 绑定已报名活动或课程；心得 300–1000 字；活动：结束+24h 窗口；课程：视频进度≥99% |
| 类型二 | 专项/比赛等 | 独立入口（仅雏英个人中心），先选模板再填事项+理由；默认分值来自模板；不绑定活动/课程 |

从活动/课程详情页直接申请时类型锁定为类型一，不可切换。审批：通过写流水；驳回必填原因。

### 5.7 图片上传系统（V1.4）

| 项 | 值 |
| --- | --- |
| 上传接口 | `POST /api/admin/upload`（multipart/form-data，需管理员登录） |
| 存储位置 | `server/public/uploads/`（Git 跟踪，随仓库分发） |
| 支持格式 | PNG / JPEG / GIF / SVG / WebP |
| 文件大小 | ≤ 10MB |
| 访问路径 | `/uploads/<filename>`（Express 静态文件服务） |
| 前端组件 | `ImageUpload`：文件选择 + 自动上传 + URL 回显 |

内容块封面、活动图片、课程封面均使用此上传系统。

### 5.8 内容运营 CMS（V1.4）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 标题 | 文本 | 内容块标题 |
| 简介 | 文本（≤500字） | 首页卡片摘要 |
| 封面图 | 上传图片 | 首页卡片展示 + 详情页头图 |
| 正文 | 富文本 HTML | 详情页完整内容（支持图文排版） |
| 跳转链接 | URL + 按钮文案 | 可选的了解更多按钮 |

首页：块按 sort_order 渲染为卡片（封面+标题+简介+查看详情），点击跳转 `/content/:key` 详情页。hero 块（`home_hero`）保留首屏横幅样式。管理后台提供简易富文本工具栏（加粗/段落/图片/链接）。

## 6. 导航与鉴权规则

| 场景 | 行为 |
| --- | --- |
| 访客访问需登录页 | 跳转 `/login?redirect=` |
| 雏英访问 `/admin/*` | 拒绝，提示无权限 |
| 管理员访问前台个人能力 | 可浏览公开页；积分/报名能力以角色为准（演示账号分流） |
| 登录成功 | 雏英 → `/me` 或 redirect；管理端角色 → `/admin` |

## 7. 分页面文档撰写约定

每份 `globaluser-*.md` 至少包含：

1. 页面概述（路由、角色、目的、类型）  
2. ASCII 线框布局（PC）  
3. 区域说明与交互（含空/错/加载）  
4. 关键字段与校验  
5. 主流程 / 分支 / 异常  
6. 接口依赖摘要（方法 + 路径意图即可）  
7. 验收要点（可测 AC）  

禁止与本总览常量冲突；缺业务数据标 `[待补充]`，禁止编造对外指标。
