## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | F14 |
| 页面名称 | 申请详情 |
| 页面路由 | `/me/applications/:id` |
| 所属模块 | 积分申请 |
| 页面类型 | 前台登录只读详情（驳回时可跳转再提） |
| 适用角色 | **仅雏英**（且仅能查看**本人**申请） |
| 页面目的 | 查看单笔积分申请的类型、内容、状态、分值与审批结果；已驳回时可发起新单 |
| 前置条件 | 会话有效且角色为雏英；申请属于当前用户；否则 404/无权限或跳转登录 |
| 终端规格 | PC Web；Chrome 90+ / Edge 90+；**1366×768**+；V1 不做移动端适配 |

### 1.1 状态展示

| 状态 | 页面表现 |
| --- | --- |
| 待审批 | 徽章「待审批」；无最终分值；提示等待审核 |
| 已通过 | 徽章「已通过」；展示**入账分值**与审批时间；可链到积分明细 |
| 已驳回 | 徽章「已驳回」；必展示驳回原因全文；主操作「修改后重新申请」（跳转 F13，预填，提交为**新单**） |

申请人在本页**不可**编辑正文或改分值；不可自行撤销已提交单（V1）。

### 2.2 区域说明

| 区域 | 规则 |
| --- | --- |
| 申请内容 | 按类型一/二切换字段；全文只读；心得展示字数 |
| 门槛摘要（类型一） | 展示提交时或当前核验摘要：线上进度是否 ≥99%、线下是否曾在 endAt+24h 内；以服务端返回为准 |
| 再申请 | 仅已驳回显示；跳转 `/me/applications/new?from=:id`（与 F13 约定一致） |
| 越权 | 访问他人 id → 统一「申请不存在」文案，不泄露是否存在 |

## 3. 字段与数据（只读）

### 3.1 公共

| 字段 | 说明 |
| --- | --- |
| id / 申请编号 | 展示用 |
| type | `activity_reflection`（类型一）/ `special`（类型二）`[待补充：枚举名与后端对齐]` |
| status | pending / approved / rejected |
| submittedAt | 提交时间 |
| reviewedAt / reviewerName | 终态时展示；演示环境可用占位 |
| pointsRequested | 申请侧展示分（配置/模板默认） |
| pointsGranted | 仅已通过 |

### 3.2 类型一 payload

| 字段 | 说明 |
| --- | --- |
| activityId / activityTitle | 关联活动 |
| activityMode | online / offline |
| progressPercent | 线上时展示 |
| reflection | 心得全文（300–1000 字提交约束见 F13） |

### 3.3 类型二 payload

| 字段 | 说明 |
| --- | --- |
| templateCode / templateName | 五预置之一 |
| matter | 具体事项 |
| reason | 申请理由 |

## 4. 交互与状态

| 场景 | 行为 |
| --- | --- |
| 加载 | 骨架屏 |
| 成功 | 渲染详情 |
| 404 / 非本人 | 「申请不存在」+ 返回列表 |
| 未登录 | `/login?redirect=/me/applications/:id` |
| 点击重新申请 | 进入 F13 并预填；原单保持已驳回 |

---

## 5. 流程

### 5.1 主流程

1. 用户从 F11 点击「详情」进入本页。  
2. 拉取本人申请详情并按类型渲染。  
3. 若已通过，可跳转 F12 查看对应流水（按 ledger 关联 id 或时间过滤 `[待补充]`）。  
4. 若已驳回，点击「修改后重新申请」→ F13 → 提交生成新 ID。

### 5.2 异常流程

| 异常 | 处理 |
| --- | --- |
| 接口失败 | Toast + 重试 |
| 审批中途状态变化 | 返回本页或轮询后刷新徽章 |

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/me/point-applications/:id` | 本人详情；含 type payload、状态、分值、驳回原因 |
| GET | `/api/me/point-ledger?applicationId=` | 可选：已通过后定位流水 `[待补充]` |

鉴权：仅本人；禁止返回他人申请。

## 7. 验收要点（AC）

1. **AC-F14-01** 未登录访问带 redirect 回本页。  
2. **AC-F14-02** 仅能打开本人申请；他人 id 不泄露存在性。  
3. **AC-F14-03** 类型一展示活动与心得全文；类型二展示模板、事项、理由。  
4. **AC-F14-04** 已通过展示入账分值；已驳回展示原因且可进入 F13 再提。  
5. **AC-F14-05** 再提提交后产生新申请 ID，本页原单仍为已驳回。  
6. **AC-F14-06** 待审批无「重新申请」、无分值编辑控件。  
7. **AC-F14-07** 1366×768 下正文可读、无横向溢出。
