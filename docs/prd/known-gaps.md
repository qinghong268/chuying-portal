## 已关闭的产品决策

| 主题 | 结论 |
| --- | --- |
| 登录字段 | 账号（邮箱）+ 密码为主；演示一键三角色保留 |
| 加入联系方式 | **单字段且须为邮箱**（用于开户） |
| 报名截止 | 等于活动开始时间；UI 不单独设「报名截止」 |
| 积分申请通道截止 | `point_apply_deadline`，发布必填，前台展示 |
| 活动心得门槛 | 结束 +24h ∩ 通道截止；**不要求**观看进度 99% |
| 课程心得门槛 | 观看进度 ≥99% |
| 心得字数 | 300–1000 |
| 用户停用 | 停用/启用前二次确认 |
| 产品正名 | 用户可见「雏英」；`@chuying/*` 保留 |
| 加入开户 | 通过且邮箱未注册 → 自动创建雏英账号并展示一次性密码 |
