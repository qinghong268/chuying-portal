## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | F09 |
| 页面名称 | 个人中心概览 |
| 页面路由 | `/me` |
| 所属模块 | 个人中心 |
| 页面类型 | 前台登录页（需雏英身份） |
| 适用角色 | **仅雏英**；访客/管理员/超管不得使用本页能力 |
| 页面目的 | 登录后着陆页：一眼看到积分余额、待办摘要，并进入报名/申请/明细/发起申请等快捷路径 |
| 前置条件 | 会话有效且角色为雏英；否则跳转 `/login?redirect=/me` |
| 终端规格 | PC Web；Chrome 90+ / Edge 90+；分辨率 **1366×768** 及以上；V1 **不做**移动端适配 |

### 1.1 鉴权硬规则

| 场景 | 行为 |
| --- | --- |
| 未登录访问 `/me` | 302/前端路由跳转至 `/login?redirect=` + 当前完整路径编码 |
| 已登录但非雏英（演示管理员等） | 拒绝进入个人中心能力；提示无权限或引导回前台公开页 `[待补充：文案]` |
| 登录成功且 redirect 指向本页 | 进入 `/me` |

## 3. 区域说明与交互

### 3.1 顶栏与子导航

| 项 | 说明 |
| --- | --- |
| 主导航 | 「个人中心」高亮；其余公开导航可点 |
| 子导航 | 概览 `/me`｜我的报名 `/me/enrollments`｜我的申请 `/me/applications`｜积分明细 `/me/points` |
| 头像菜单 | 含退出等；细则见账号/登录文档 |

### 3.2 积分余额

| 项 | 说明 |
| --- | --- |
| 展示 | 当前可用积分余额（整数或一位小数，以实现为准；展示格式 `[待补充]`） |
| 来源 | `PointLedger` 汇总或用户积分字段 |
| 交互 | 「查看明细」→ `/me/points` |
| 加载 | 数字骨架占位 |
| 错误 | Toast「积分加载失败」+ 重试；区块显示「--」 |

### 3.3 待办

| 项 | 说明 |
| --- | --- |
| 可发起申请数 | 当前用户满足发起条件、且尚可提交的申请机会数量（含类型一可申请活动数等聚合口径）`[待补充：是否含类型二始终可申]` |
| 审批中 | 状态为「待审批」的 `PointApplication` 条数 |
| 「去申请」 | → `/me/applications/new`（F13） |
| 「查看申请」 | → `/me/applications`（F11） |
| 空待办 | 文案「暂无待办」；仍保留快捷入口 |

### 3.4 快捷入口

| 入口 | 跳转 |
| --- | --- |
| 我的报名 | `/me/enrollments` |
| 我的申请 | `/me/applications` |
| 积分明细 | `/me/points` |
| 发起积分申请 | `/me/applications/new` |

## 4. 关键字段与校验

本页**无用户输入表单**。展示字段：

| 字段（逻辑） | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| displayName | 文本 | 可空时降级为「雏英」或账号名 | 欢迎条 |
| balance | 数值 | ≥0 | 积分余额 |
| eligibleCount | 整数 | ≥0 | 可申请数 |
| pendingCount | 整数 | ≥0 | 待审申请数 |
| accountStatus | 枚举 | active / disabled 等 | 禁用时提示并限制申请入口 `[待补充]` |

## 5. 处理流程

### 5.1 主流程

1. 用户访问 `/me`。  
2. 系统校验登录且角色为雏英；失败则跳转 `/login?redirect=/me`。  
3. 并行拉取概览摘要（余额、待办计数、用户展示名）。  
4. 渲染余额、待办、快捷入口。  
5. 用户点击入口进入对应子页。

### 5.2 分支流程

| 分支 | 行为 |
| --- | --- |
| eligibleCount > 0 点「去申请」 | 进入 F13 |
| pendingCount > 0 点「查看申请」 | 进入 F11，可选默认筛「待审批」`[待补充]` |
| 账号禁用 | 只读展示余额与历史入口；隐藏或禁用「发起积分申请」 |

### 5.3 异常流程

| 异常 | 处理 |
| --- | --- |
| 会话过期 | 跳转 login 并带 redirect |
| 摘要接口失败 | Toast + 重试；已渲染区块保留 |
| 网络超时 | 同失败处理 |

## 7. 验收要点（AC）

1. **AC-F09-01** 未登录访问 `/me` 跳转至 `/login?redirect=`，且 redirect 解码后回到 `/me`。  
2. **AC-F09-02** 雏英登录后可见积分余额、可申请数、待审数三块核心信息（或等价聚合）。  
3. **AC-F09-03** 「查看明细」「去申请」「查看申请」及四个快捷入口跳转路径正确。  
4. **AC-F09-04** 子导航「概览」高亮；顶栏「个人中心」高亮。  
5. **AC-F09-05** 摘要接口失败时不白屏，提供重试。  
6. **AC-F09-06** 非雏英角色无法正常使用本页业务能力。
