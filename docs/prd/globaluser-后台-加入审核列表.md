## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A03 |
| 页面名称 | 加入审核列表 |
| 页面路由 | `/admin/join` |
| 页面类型 | 管理后台列表页（PC 表格） |
| 适用角色 | 管理员、超级管理员 |
| 所需权限包 | `join_review`（加入审核） |
| 页面目的 | 运营人员浏览、筛选加入申请（`JoinApplication`），进入详情完成通过/驳回 |
| 前置条件 | 已登录管理端且持有 `join_review`；否则侧栏隐藏，直链无权限页 |

业务背景（与设计规格 §4.1 一致）：访客提交加入申请后状态为「待审核」；持本权限包的管理员通过后账号具备雏鹰身份（或激活已有账号），驳回须填写原因。

## 3. 区域说明与交互

| 区域 | 说明与交互 |
| --- | --- |
| 状态筛选 | 默认「待审核」，便于日常运营；切换后重新请求列表 |
| 时间范围 | 按申请提交时间过滤；结束日期含当日 |
| 关键词 | 模糊匹配姓名、手机号、邮箱（字段以后台实际采集为准） |
| 表格 | PC 后台表格；状态用 Badge：待审核（橙）/ 已通过（绿）/ 已驳回（红） |
| 操作「详情」 | 跳转 `/admin/join/:id`（A04） |
| 行点击 | 整行可点进入详情（与按钮一致） |
| 加载/错 | 表格骨架屏；失败 Toast + 重试 |
| 分页 | 默认每页 20；保留筛选条件 |

本页**不提供**列表行内一键通过/驳回（避免误触）；审核动作在详情页完成。若实现阶段需行内快捷操作，须二次确认且驳回弹窗必填原因。

## 4. 关键字段与校验

列表列（只读展示）：

| 列 | 说明 |
| --- | --- |
| 申请编号 | 业务可读 ID 或短码 |
| 姓名 | 申请人填写 |
| 联系方式 | 手机或邮箱脱敏展示（中间位 `*`） |
| 学校/单位 | 可空显示「—」 |
| 提交时间 | `YYYY-MM-DD HH:mm` |
| 状态 | pending / approved / rejected |

筛选表单校验：开始时间不得晚于结束时间，否则字段下提示并阻止查询。

---

## 5. 主流程 / 分支 / 异常

**主流程**：进入列表（默认待审核）→ 必要时筛选 → 点详情 →（在 A04 审核）。

**分支流程**：切换「已通过/已驳回」查看历史；关键词定位单人。

**异常流程**：

| 场景 | 系统行为 |
| --- | --- |
| 无 `join_review` | 无权限页 |
| 详情 ID 已删除 | 详情页提示不存在，返回列表 |
| 列表超时 | Toast「加载失败」可重试 |

## 7. 验收要点（AC）

1. 仅 `join_review`（或超管）可见菜单并打开本页。  
2. 默认筛选「待审核」，条数与控制台待审摘要一致（同筛选口径）。  
3. 状态、时间、关键词组合筛选结果正确。  
4. 点击「详情」进入 `/admin/join/:id`。  
5. 无权限直链展示无权限页。  
6. 空列表与加载失败态符合总览交互规范。
