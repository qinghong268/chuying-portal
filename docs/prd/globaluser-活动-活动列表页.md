## 1. 页面概述

### 1.1 基本信息

| 属性 | 说明 |
| --- | --- |
| 页面路由 | `/activities` |
| 适用角色 | 访客、雏英（只读浏览）；管理员/超管可浏览公开列表，无前台报名能力 |
| 页面目的 | 展示已发布活动的卡片列表，支持按形态与状态筛选，引导进入活动详情 |
| 页面类型 | 前台公开页（顶栏 + 页脚壳） |
| 适配终端 | PC Web；Chrome 90+ / Edge 90+ |
| 入口 | 顶栏导航「活动」；首页/介绍页 CTA「查看活动」 |

### 1.2 核心功能（动词短语）

| 功能点 | 类型 | 优先级 | 描述 |
| --- | --- | --- | --- |
| 浏览活动列表 | 新增 | P0 | 拉取已发布活动并分页展示 |
| 筛选活动 | 新增 | P0 | 按形态（线上/线下）与状态（报名中/进行中/已结束）筛选 |
| 进入活动详情 | 新增 | P0 | 点击卡片跳转 `/activities/:id` |

### 1.3 功能关系（逻辑层级）

```
活动运营
├── 浏览活动列表 [平级] ← 本页主能力
├── 筛选活动 [平级]
├── 浏览活动详情 [平级]（F04）
└── 报名活动 [平级]（在 F04 完成，本页不提供报名按钮）
```

### 1.4 本页不做（Out of Scope）

- 本页不提供报名、取消报名、提交心得（均在详情或个人中心）。
- 不展示后台草稿/已下架活动。
- 不做移动端适配、不提供地图聚合筛选。

## 3. 区域说明与交互

### 3.1 页头与筛选

| 区域 | 交互与规则 |
| --- | --- |
| 标题「活动」 | 固定文案；副标题说明用途，不堆统计条 |
| 形态筛选 | 枚举：全部 / 线上 / 线下；默认「全部」；变更后重置到第 1 页并重新请求 |
| 状态筛选 | 枚举：全部 / 报名中 / 进行中 / 已结束；默认「全部」；状态计算规则见 §4.2 |
| 关键词搜索 | 匹配标题；防抖 300ms；空串等同清除；`[待补充]` 是否搜简介 |

### 3.2 活动卡片

| 元素 | 规则 |
| --- | --- |
| 封面 | 取活动封面 URL；无则占位 |
| 标题 | 最多 2 行，超出省略 |
| 形态标签 | 「线上」或「线下」 |
| 状态标签 | 「报名中」「进行中」「已结束」三选一（互斥展示） |
| 时间 | 展示开始–结束；线下可附地点一行摘要 |
| CTA | 文案「查看详情」；整卡可点，跳转 `/activities/:id` |

### 3.3 空 / 错 / 加载

| 状态 | 表现 |
| --- | --- |
| 加载 | 卡片区骨架屏（3×2 占位） |
| 空列表 | 文案「暂无符合条件的活动」+ 按钮「清除筛选」（有筛选时）或「返回首页」 |
| 接口失败 | Toast「活动列表加载失败」+ 「重试」按钮 |
| 分页无更多 | 末页隐藏「下一页」或置灰 |

## 4. 关键字段与校验

### 4.1 列表项展示字段

| 字段 | 来源 | 说明 |
| --- | --- | --- |
| `id` | Activity | 路由参数 |
| `title` | Activity | 必填 |
| `coverUrl` | Activity | 可空 |
| `mode` | Activity | `online` / `offline` |
| `startAt` / `endAt` | Activity | ISO 时间戳 |
| `enrollDeadlineAt` | Activity | 线上报名截止；线下可空（线下以开始前为准） |
| `locationSummary` | Activity | 线下地点摘要；线上可显示「线上」 |
| `statusLabel` | 前端或接口计算 | 见下表 |
| `published` | Activity | 仅 `true` 出现在本列表 |

### 4.2 状态标签计算（前台展示）

| 标签 | 判定（默认，冲突时以后端为准并标 `[待补充]`） |
| --- | --- |
| 报名中 | 当前时间早于报名截止窗口，且活动未结束 |
| 进行中 | 当前时间 ≥ 开始且 ≤ 结束 |
| 已结束 | 当前时间 > 结束 |

说明：线上「报名截止」字段为 `enrollDeadlineAt`；线下报名窗口为「活动开始前」（详见 F04），列表标签不必拆出「可报名」细分，详情页再精确控制按钮。

### 4.3 查询参数

| 参数 | 类型 | 校验 |
| --- | --- | --- |
| `mode` | enum | 空 / online / offline |
| `status` | enum | 空 / enrolling / ongoing / ended |
| `q` | string | 最长 50；trim |
| `page` | int | ≥1，默认 1 |
| `pageSize` | int | 默认 12；上限 `[待补充]`（建议 24） |

## 5. 主流程 / 分支 / 异常

### 5.1 主流程

1. 用户打开 `/activities`（或从导航进入）。  
2. 系统按默认筛选拉取第 1 页已发布活动。  
3. 用户浏览卡片，点击「查看详情」。  
4. 路由跳转 `/activities/:id`（F04）。

### 5.2 分支流程

| 分支 | 行为 |
| --- | --- |
| 变更筛选/搜索 | 重置页码为 1 并重新请求 |
| 翻页 | 保持筛选条件，请求对应页 |
| 带 query 直达 | 如 `/activities?mode=online`，初始化筛选项并请求 |

### 5.3 异常流程

| 异常 | 反馈 |
| --- | --- |
| 网络/5xx | Toast + 重试，保留当前筛选 |
| 非法 query | 忽略非法值，回退默认枚举 |
| 活动在列表可见但详情已下架 | 进入详情后由 F04 展示「活动不存在或已下架」 |

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/activities` | 查询已发布活动列表；支持 mode/status/q/page/pageSize |
| — | — | 本页无写接口 |

响应列表项至少包含：`id, title, coverUrl, mode, startAt, endAt, enrollDeadlineAt, locationSummary, status`（或足够前端计算 status 的字段）。

## 7. 验收要点（AC）

1. 未登录访客可打开 `/activities` 并看到已发布活动卡片，无需登录。  
2. 形态筛选「线上」仅展示 `mode=online` 的活动；「线下」同理。  
3. 状态筛选切换后列表与页码正确刷新；空结果展示空态而非白屏。  
4. 点击卡片或「查看详情」进入 `/activities/:id`，且 `id` 与卡片一致。  
5. 加载中展示骨架屏；接口失败可点「重试」再次请求。  
6. 下架/草稿活动不出现在列表中。  
7. 页面在 1366×768 下三列布局完整可见，无移动端专属断点要求。  
8. 顶栏「活动」为当前高亮项。
