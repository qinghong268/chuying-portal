## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A06 |
| 页面名称 | 活动编辑（新建 / 编辑） |
| 页面路由 | `/admin/activities/new`、`/admin/activities/:id/edit` |
| 页面类型 | 管理后台表单页 |
| 适用角色 | 管理员、超级管理员 |
| 所需权限包 | `activity` |
| 页面目的 | 创建或修改活动配置：形态（线上/线下）、时间窗、报名规则、目标积分、介绍内容与进度源等，供前台展示与报名、积分门槛判定 |
| 前置条件 | 持有 `activity`；编辑态活动 ID 存在 |

报名业务规则（写入配置时须可表达，与设计规格 §4.2 一致）：

- **线上**：报名截止前可报名（依赖 `enrollDeadline`）。  
- **线下**：须在**活动开始前**完成报名（开始后不可报名）。

## 3. 区域说明与交互

| 区域 | 说明与交互 |
| --- | --- |
| 形态切换 | 切换 online/offline 时联动：线上启用并必填报名截止；线下清空或忽略报名截止并展示说明文案 |
| 存草稿 | 校验基础必填（标题、形态、开始/结束）后保存 `draft`，不出现在前台可报名单 |
| 保存并发布 | 全量校验通过后 `published`；成功回列表或留编辑页 Toast |
| 取消 | 有未保存变更则二次确认 |
| 编辑已发布 | 允许改文案与目标积分；若已有报名，变更开始时间须警示「已有 N 人报名」`[推断：产品保护]` |
| 加载 | 编辑页拉详情骨架屏；失败返回列表 |

## 4. 关键字段与校验

| 字段 | 必填 | 校验与说明 |
| --- | --- | --- |
| title | 是 | 1–80 字 |
| form | 是 | `online` \| `offline` |
| startAt | 是 | 合法日期时间 |
| endAt | 是 | 必须 **晚于** startAt |
| enrollDeadline | 线上必填 | 必须 **早于或等于** startAt（建议早于开始）；须早于 endAt；线下不填 |
| targetPoints | 是 | 正整数；建议 1–9999 |
| coverUrl | 否 | 图片 |
| summary | 否 | ≤200 字 |
| location | 线下建议必填 | 线下空则警告或拦截发布 `[待补充]` |
| onlineUrl | 线上建议必填 | 观看/直播入口 |
| detailHtml | 发布时建议必填 | 富文本 |
| progressSource | 线上可选 | 关联课程或播放标识，供 `WatchProgress` 对齐 |
| capacity | 否 | 正整数或空 |

常量提示（只读文案，非表单字段）：线上进度阈值 **99%**；线下申请窗口 **结束时间 + 24 小时**（与总览 §5.4 一致）。

## 5. 主流程 / 分支 / 异常

**主流程（新建发布）**：新建 → 选形态 → 填时间与目标积分（线上含报名截止）→ 填详情 → 保存并发布 → 前台活动列表可见。

**分支流程**：存草稿后稍后发布；编辑已有活动后保存。

**异常流程**：

| 场景 | 系统行为 |
| --- | --- |
| 无 `activity` | 无权限页 |
| endAt ≤ startAt | 字段错误「结束时间必须晚于开始时间」 |
| 线上缺少 enrollDeadline | 「报名截止为必填」 |
| enrollDeadline 晚于不合理点 | 按校验提示修正 |
| ID 不存在 | 404 提示并回列表 |

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/activities/:id` | 编辑回填 |
| POST | `/api/admin/activities` | 新建 |
| PUT | `/api/admin/activities/:id` | 更新 |
| POST | `/api/admin/activities/:id/publish` | 发布（若与保存合并可省略） |
| POST | `/api/admin/upload` | 封面上传 |

请求体须能承载：`form`、`startAt`、`endAt`、`enrollDeadline`、`targetPoints` 及详情字段。

---

## 7. 验收要点（AC）

1. 新建线上活动：报名截止必填；校验结束时间必须晚于开始时间。  
2. 新建线下活动：报名截止控件禁用或不展示，保存成功且列表截止列为「—」。  
3. 目标积分必填且为正整数。  
4. 发布后前台详情展示形态、时间与报名规则一致。  
5. 无权限直链 new/edit 为无权限页。  
6. 存草稿不出现在前台可报名列表。
