## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A12 |
| 页面名称 | 数据看板 |
| 页面路由 | `/admin/dashboard` |
| 权限包 | `dashboard` |
| 适用角色 | 已授予 `dashboard` 的管理员；超级管理员 |
| 页面目的 | 一屏总览计划运营关键指标，辅助运营发现待办与趋势 |
| 页面类型 | 后台只读仪表盘（卡片 + 简表/趋势占位） |
| 前置条件 | 已登录且持有 `dashboard` |

### 1.1 指标口径说明（禁止编造对外承诺）

以下指标为 V1 **建议展示口径**。基线、目标值、环比阈值一律标 `[待核实]`，**不得**在对外材料中写成已承诺数字。页面上可展示实时统计值；文档不写死示例业绩。

| 指标 | 口径（建议） | 基线/目标 |
| --- | --- | --- |
| 雏英用户数 | 角色=雏英且状态正常的账号数 | `[待核实]` |
| 待审加入申请 | 加入申请状态=待审核 | `[待核实]` |
| 待审积分申请 | 积分申请状态=待审批 | `[待核实]` |
| 活动数（进行中） | 当前时间落在活动开始–结束内，或业务定义的「进行中」状态 | `[待核实]` |
| 近 7 日活动报名数 | 最近 7 个自然日成功报名次数 | `[待核实]` |
| 近 7 日积分入账笔数 | 最近 7 日 `PointLedger` 加分流水笔数 | `[待核实]` |
| 近 7 日积分入账总分 | 同上流水 delta 求和 | `[待核实]` |
| 官网 UV/PV | 若无埋点则隐藏或显示「暂无数据」 | `[待核实]` 采集方案 |

## 3. 区域说明与交互

| 区域 | 规则 |
| --- | --- |
| 指标卡片 | 只读数字；点击「待审加入/待审积分」卡片跳转对应列表；其余卡片 V1 可不跳转 |
| 刷新 | 手动刷新重新拉汇总；展示「更新于」时间戳 |
| 快捷待办 | 与摘要同源；无权限的目标页则链接隐藏或点击进无权限页（与全局一致） |
| 趋势图 | P1；无接口时整区隐藏，不展示假曲线 |
| 加载 | 卡片骨架屏 |
| 错误 | 卡片显示「—」+ 顶部可重试；禁止用虚构数字填充 |
| 空数据 | 真实 0 显示 `0`，与加载失败「—」区分 |

## 4. 关键字段与校验

本页无表单。汇总接口字段与 §1.1 指标一一对应即可。时间窗「近 7 日」按服务器时区，文档暂定 **Asia/Shanghai** `[待核实]`。

---

## 5. 主流程 / 分支 / 异常

### 5.1 主流程

1. 管理员进入 `/admin/dashboard`。  
2. 系统返回汇总指标并渲染。  
3. 管理员点击「待审积分申请」进入审批列表处理。

### 5.2 分支

| 分支 | 行为 |
| --- | --- |
| 部分指标无数据源 | 该卡片显示「暂无数据」，不影响其它卡片 |
| 手动刷新 | 重新请求；按钮 loading |

### 5.3 异常

| 场景 | 处理 |
| --- | --- |
| 汇总接口失败 | 不展示假数；可重试 |
| 无权限 | 无权限页 |

## 6. 接口依赖摘要

| 意图 | 方法 | 路径（示意） |
| --- | --- | --- |
| 看板汇总 | GET | `/api/admin/dashboard/summary` |
| 近 7 日序列（P1） | GET | `/api/admin/dashboard/series?metric=&days=7` |

`summary` 响应示例字段（值由环境真实统计，文档不给业绩样例）：  
`eagleCount`, `pendingJoinCount`, `pendingPointAppCount`, `activeActivityCount`, `enrollmentsLast7d`, `ledgerCountLast7d`, `ledgerPointsLast7d`, `generatedAt`。

## 7. 验收要点（AC）

1. 持有 `dashboard` 可访问；无权限直链无权限页。  
2. 页面展示 §1.1 中 V1 必选卡片（至少：雏英数、待审加入、待审积分、进行中活动、近 7 日报名/入账笔数）。  
3. 接口失败时显示「—」或错误态，**不出现编造数字**。  
4. 待审类卡片/快捷入口可跳到加入审核列表、积分审批列表。  
5. 「更新于」时间与刷新行为正确。  
6. 文档与 UI 文案不出现未核实的对外承诺阈值。
