## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | F13 |
| 页面名称 | 发起积分申请 |
| 页面路由 | `/me/applications/new` |
| 所属模块 | 积分申请 |
| 页面类型 | 前台登录表单页（需雏英身份） |
| 适用角色 | **仅雏英** |
| 页面目的 | 提交类型一（活动完成心得）或类型二（专项/比赛等模板）积分申请 |
| 前置条件 | 会话有效且角色为雏英；否则跳转 `/login?redirect=/me/applications/new`（含 query） |
| 终端规格 | PC Web；Chrome 90+ / Edge 90+；**1366×768**+；V1 不做移动端适配 |

### 1.1 申请类型硬规则

#### 类型一：活动/课程完成心得

| 项 | 规则 |
| --- | --- |
| 绑定 | **必须**绑定本人已报名的**活动**或**课程**（`activityId` 或 `courseId`；详情入口可预填并锁定类型一） |
| 活动 | 已结束且 `now` ∈ `[endAt, endAt+24h]`，且未超过 `pointApplyDeadline`；**不要求**进度 ≥99% |
| 课程 | 观看进度 ≥99%（`WATCH_PROGRESS_THRESHOLD`）；无结束时间窗 |
| 心得 | **300–1000 字** |
| 分值 | 活动：目标积分只读；课程：可为空由审批人定；申请人不可改 |

#### 类型二：专项/比赛等

| 项 | 规则 |
| --- | --- |
| 选模板 | 先选自启用模板：`contest_award` / `speech` / `project_contrib` / `honor` / `other_special` |
| 填写 | **具体事项** + **申请理由**（必填） |
| 分值 | 展示模板默认分值（只读）；申请人**不可改**；审批人可改最终分值（后台） |
| 附件 | V1 是否支持上传 `[待补充]`；未定前表单不含附件 |

#### 驳回后再提

文档预留：**修改后重新提交为新单**（不复活原单）。可从 F11 带 `fromRejectedId` 进入本页做预填参考，提交仍 `POST` 新建。

## 3. 区域说明与交互

### 3.1 类型切换

| 项 | 说明 |
| --- | --- |
| 默认 | 无 query 时不预选或默认类型一 `[待补充]` |
| 预填 | `?type=activity&activityId=` 来自 F10；`?type=template&templateCode=` 可选 |
| 切换类型 | 清空对方字段；二次确认若已填写 `[待补充：是否确认]` |

### 3.2 类型一：活动下拉

| 项 | 说明 |
| --- | --- |
| 选项来源 | 服务端返回「当前可申请类型一」的报名列表 |
| 空列表 | 说明不可申请原因汇总 + 链到「我的报名」/「活动列表」 |
| 选中后 | 展示进度/窗口只读信息；不满足门槛的活动不得出现在可选项中 |

### 3.3 类型二：模板

| 项 | 说明 |
| --- | --- |
| 展示名 | 比赛获奖、分享宣讲、项目贡献、荣誉表彰、其他专项 |
| 停用模板 | 不出现在下拉中 |
| 分值控件 | **禁止**输入框编辑；纯展示 |

### 3.4 提交

| 项 | 说明 |
| --- | --- |
| 校验 | 失焦 + 提交全量；错误贴字段下方 |
| 成功 | Toast「提交成功」→ 跳转 F14 新单详情或 F11 列表 `[待补充：默认落地]` |
| 失败 | Toast 服务端错误信息；表单保留 |

### 3.5 取消

返回 F11 或 `history.back()`；有未提交内容时确认离开 `[待补充]`。

## 4. 关键字段与校验

### 4.1 类型一

| 字段 | 必填 | 校验 |
| --- | --- | --- |
| activityId | 是 | 必须为本人可申请报名对应活动 |
| reflection | 是 | 长度 300–1000（字符）；空白是否计入 `[待决]` |
| points | — | 只读，不提交由服务端按配置确定 |

### 4.2 类型二

| 字段 | 必填 | 校验 |
| --- | --- | --- |
| templateCode | 是 | 属于启用中的预置/配置模板 |
| title / specificMatter | 是 | 具体事项；长度上限 `[待补充]`，建议 ≤100 字 |
| reason | 是 | 申请理由；长度上限 `[待补充]`，建议 ≤500 字 |
| points | — | 只读默认分；请求体不得由前端篡改生效（服务端以模板为准） |

### 4.3 服务端再校验（须实现）

- 类型一：活动按结束窗 + 通道截止；课程按进度 ≥99%；防前端绕过。  
- 类型二忽略客户端自带分值。  
- 鉴权：仅雏英。

## 5. 处理流程

### 5.1 主流程（类型一）

1. 进入页 → 选类型一 → 拉取可申请活动。  
2. 选择活动 → 填写心得 300–1000 字。  
3. 提交 → 服务端校验门槛 → 创建 `PointApplication` 状态「待审批」。  
4. 跳转详情或列表。

### 5.2 主流程（类型二）

1. 选类型二 → 拉取启用模板列表。  
2. 选模板 → 填具体事项与申请理由（分值只读）。  
3. 提交 → 待审批。

### 5.3 分支流程

| 分支 | 行为 |
| --- | --- |
| 从驳回再提进入 | 可预填事项/理由/心得供编辑；提交新建 ID |
| 可申请活动为空 | 禁用提交；引导补进度或等待线下窗口 |
| URL 带非法 activityId | 忽略预填并提示「该活动当前不可申请」 |

### 5.4 异常流程

| 异常 | 处理 |
| --- | --- |
| 未登录 | `/login?redirect=` 完整 URL |
| 提交时门槛失效（进度回退/窗口过期） | 422 + 明确文案；刷新可申请列表 |
| 重复待审（若规则禁止） | 拒绝并链到已有申请 `[待决：同活动是否唯一]` |
| 网络错误 | Toast + 可重试；防重复提交（按钮 loading） |

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/me/point-applications/eligible-activities` | 类型一可选活动 |

## 7. 验收要点（AC）

1. **AC-F13-01** 未登录跳转 `/login?redirect=` 且可回到本页。  
2. **AC-F13-02** 类型一活动：仅已报名且满足结束+24h∩通道截止的活动可选；类型一课程：仅进度≥99% 的已报名课程可选。  
3. **AC-F13-03** 心得少于 300 或多于 1000 字不可提交；边界 300、1000 可提交。  
4. **AC-F13-04** 类型二必须先选模板，再填具体事项与申请理由；页面无分值编辑控件。  
5. **AC-F13-05** 篡改请求体中的分值不影响落库默认分（以服务端模板/活动配置为准）。  
6. **AC-F13-06** 提交成功后申请出现在「我的申请」且状态为待审批。  
7. **AC-F13-07** 从已驳回「再申请」提交后产生**新**申请 ID，原单仍为已驳回。
