## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A01 |
| 页面名称 | 后台控制台 |
| 页面路由 | `/admin` |
| 页面类型 | 管理后台着陆页（概览 + 待办入口） |
| 适用角色 | 管理员、超级管理员（已登录且角色为管理端） |
| 所需权限包 | 无独立权限包；能进入后台即可访问本页。侧栏其它菜单仍按权限包显隐 |
| 页面目的 | 登录后台后的默认着陆页：展示与当前账号权限相关的待办摘要与快捷入口，引导进入内容、审核、活动等运营模块 |
| 前置条件 | 当前会话角色为管理员或超级管理员；雏鹰/访客访问 `/admin` 被拒绝并提示无权限（见总览 §6） |

### 1.1 后台壳（全后台共用，本页为壳内首屏）

| 规则 | 说明 |
| --- | --- |
| 布局 | 顶栏 + 左侧栏（约 220px）+ 主内容区（max 1280px） |
| 侧栏显隐 | 按账号已授予权限包决定菜单项；未授予的菜单不展示 |
| 直链无权限 | 用户手动输入无权限路由时，主内容区展示「无权限」页，不泄露业务数据 |
| 顶栏 | 后台标题「雏鹰计划 · 管理后台」、当前账号显示名、退出、回前台 |

侧栏菜单与权限包映射（V1）：

| 菜单文案 | 路由 | 权限包 code |
| --- | --- | --- |
| 控制台 | `/admin` | （后台角色即可） |
| 内容运营 | `/admin/content` | `content` |
| 加入审核 | `/admin/join` | `join_review` |
| 活动管理 | `/admin/activities` | `activity` |
| 积分类型 | `/admin/point-types` | `point_type` |
| 积分审批 | `/admin/point-apps` | `point_review` |
| 用户管理 | `/admin/users` | `user` |
| 数据看板 | `/admin/dashboard` | `dashboard` |
| 权限管理 | `/admin/permissions` | `permission`（仅超管） |

## 3. 区域说明与交互

| 区域 | 说明与交互 |
| --- | --- |
| 待办摘要卡 | 仅统计当前账号**有权限**查看的待办：有 `join_review` 显示待审加入数；有 `point_review` 显示待批积分数；有 `activity` 显示进行中（已发布且未结束）活动数。无对应权限则不展示该卡 |
| 快捷入口 | 按钮跳转对应列表页；无权限的按钮不渲染 |
| 最近动态 | V1 可选：最近审核/发布操作摘要；若接口未就绪可隐藏整块并标实现阶段裁剪 |
| 加载态 | 摘要区骨架屏；失败 Toast「加载失败」+「重试」 |
| 空态 | 有权限但待办为 0：卡片显示 0，文案「暂无待办」 |
| 侧栏高亮 | 当前路由为 `/admin` 时「控制台」高亮 |

## 4. 关键字段与校验

本页无提交表单。摘要字段只读：

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| pendingJoinCount | 状态为待审核的加入申请数 | 整数 ≥0；无 `join_review` 不请求 |
| pendingPointAppCount | 状态为待审批的积分申请数 | 整数 ≥0；无 `point_review` 不请求 |
| activeActivityCount | 已发布且当前时间在开始～结束内的活动数 | 整数 ≥0；无 `activity` 不请求 |

## 5. 主流程 / 分支 / 异常

**主流程**：管理员登录成功 → 进入 `/admin` → 按权限拉取摘要 → 点击快捷入口进入业务页。

**分支流程**：

1. 超管：侧栏含「权限管理」；摘要可覆盖全部有权限模块。  
2. 仅持部分权限包：仅见对应卡片与入口。  
3. 无任何业务权限包：仍可见控制台，摘要区提示「尚未分配运营权限，请联系超管」。

**异常流程**：

| 场景 | 系统行为 |
| --- | --- |
| 未登录访问 | 跳转 `/login?redirect=/admin` |
| 雏鹰访问 | 拒绝，提示无权限，不进入后台壳 |
| 摘要接口失败 | Toast + 重试；已渲染侧栏仍可用 |
| Session 过期 | 跳转登录并带回 redirect |

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/me` | 当前管理员资料与已授予权限包 code 列表 |
| GET | `/api/admin/console/summary` | 按权限返回待审加入、待批积分、进行中活动等计数 |
| POST | `/api/auth/logout` | 退出登录 |

---

## 7. 验收要点（AC）

1. 管理员/超管登录后默认进入 `/admin`，可见顶栏与按权限显隐的侧栏。  
2. 无 `join_review` 时不出现「待审加入」卡与「去审核加入」；有权限时计数与列表待审数一致。  
3. 雏鹰或访客访问 `/admin` 无法看到后台业务数据。  
4. 直链访问无权限业务路由（如无 `content` 访问 `/admin/content`）展示无权限页，且提供返回控制台。  
5. 摘要加载失败可重试，不阻塞侧栏导航。
