## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | F12 |
| 页面名称 | 积分明细 |
| 页面路由 | `/me/points` |
| 所属模块 | 个人中心 |
| 页面类型 | 前台登录页（需雏英身份） |
| 适用角色 | **仅雏英** |
| 页面目的 | 展示当前积分余额与积分流水（入账来源、时间、变动额），便于核对审批结果 |
| 前置条件 | 会话有效且角色为雏英；否则跳转 `/login?redirect=/me/points` |
| 终端规格 | PC Web；Chrome 90+ / Edge 90+；**1366×768**+；V1 不做移动端适配 |

### 1.1 范围说明（V1）

| 支持 | 不支持（Out of Scope） |
| --- | --- |
| 审批通过产生的入账流水 | 积分商城、排行榜、积分过期 |
| 只读查询与分页 | 用户侧调账、转赠 |
| 余额与流水一致可核对 | 报名即自动加分 |

## 3. 区域说明与交互

### 3.1 余额卡

| 项 | 说明 |
| --- | --- |
| 余额 | 与 F09 同源；本页为权威核对入口之一 |
| 发起申请 | → F13 |
| 加载/错误 | 骨架；失败显示「--」+ 重试 |

### 3.2 流水表

| 列 | 说明 |
| --- | --- |
| 时间 | 入账时间 |
| 变动 | 带符号金额，如 `+20`；V1 以入账为主，若存在管理员调账则同样展示 `[待补充：是否开放调账]` |
| 余额快照 | 该笔之后的余额（若后端未存则可不展示该列）`[待补充]` |
| 来源说明 | 类型一/二可读描述 |
| 关联申请 | 有则链到 F14；无关联则「—」 |

### 3.3 排序

默认按时间**倒序**（最新在上）。

| 查询字段 | 类型 | 说明 |
| --- | --- | --- |

无写表单。

## 5. 处理流程

### 5.1 主流程

1. 鉴权 → 拉取余额 + 流水分页。  
2. 用户筛选时间后刷新。  
3. 点击关联申请查看审批详情。

### 5.2 分支流程

| 分支 | 行为 |
| --- | --- |
| 从 F09「查看明细」进入 | 直接本页 |
| 无流水但有余额 | 展示余额 + 空流水说明（异常数据标运维）`[待补充]` |

### 5.3 异常流程

| 异常 | 处理 |
| --- | --- |
| 未登录 | `/login?redirect=/me/points` |
| 接口失败 | Toast + 重试 |
| 关联申请已删 | 链接禁用或提示不可用 |

## 7. 验收要点（AC）

1. **AC-F12-01** 未登录访问跳转 `/login?redirect=/me/points`。  
2. **AC-F12-02** 展示当前余额；与概览页在同一时刻数据一致（允许短缓存，刷新后对齐）。  
3. **AC-F12-03** 审批通过后新流水出现在列表（倒序）。  
4. **AC-F12-04** 有关联申请时可跳转 F14。  
5. **AC-F12-05** 无流水时展示空状态与发起申请入口。  
6. **AC-F12-06** 用户无法在本页修改分值或删除流水。
