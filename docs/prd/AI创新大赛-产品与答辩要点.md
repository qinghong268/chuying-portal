## 4. 功能之外的加分点

1. **真实场景**：SoftTong 雏英培养，角色与权限包清晰  
2. **工程方法**：PRD / AC / known-gaps / 测试（99 用例）——AI 辅助研发，人做决策与验收  
3. **可交接资产**：公开仓、README 可部署、PRD 可查阅  
4. **边界坦诚**：不做移动端/SSO/商城写清楚，显成熟  
5. **Demo 剧本（增强版）**：2～3 分钟跑通整条 AI 增强链路  
6. **价值量化**：审核耗时降低（AI 预审 2-10 秒 vs 人工 1-3 分钟）、文案生成（AI 30 秒 vs 人工 5-10 分钟）、学习推荐可量化点击率

答辩可用三句：

1. 场景对准人才培养运营，AI 嵌在审核/内容/学习三条主链路里——不是外挂聊天。  
2. 方法上有规格与缺口管理、测试用例、浏览器端到端验证——保证能演示、能讲边界。  
3. 代码与文档可交接，创新可落地、可复用。

## 6. Demo 路径（增强版，约 3 分钟）

1. 访客提交加入（邮箱 contact）→ 管理员通过 → **一键复制账号密码**  
2. 雏英登录 → **通知弹窗**提示活动和课程情况  
3. 雏英报名活动/课程 → 完成进度 → 提交心得  
4. 管理员打开审批 → **AI 预审面板**展示评分+风险标签+建议分值 → **填入建议分**→ 通过并入账  
5. 管理员看**数据看板**：AI 洞察条 + 待办队列（AI 风险排序）+ 趋势图 + 明细抽屉  
6. 管理员点**生成周报** → AI 为每位雏英生成学习小结  
7. **新能力展示**：CMS 文案 AI 草稿 → 学习路径推荐 → 雏英画像雷达图  
8. 收束：规则管窗口与门槛，AI 管质量+效率+推荐，人做最终决策

## 8. 本轮迭代执行规划（🔧 项）

### 8.1 AI 辅助 CMS 文案草稿生成

**目标**：管理员在内容运营编辑页输入主题关键词，一键生成标题+简介+正文 HTML 草稿。

**实现方案**：
- 后端：`POST /api/admin/content/ai-draft` — 接收 `{ topic, style? }` → 调 DeepSeek 生成结构化文案
- DeepSeek prompt：生成 `{ title, summary, body }` JSON，body 为 HTML 格式（含 h2/p/ul）
- 前端：ContentPage 编辑面板加「🤖 AI 生成草稿」按钮 → 弹窗输入主题关键词 → 调用 API → 自动填入标题/简介/正文
- 限制：maxTokens 800，temperature 0.7

**改动文件**：`server/src/routes/admin/content.ts`（+1 路由）、`ContentPage.tsx`（+按钮+弹窗）

---

### 8.2 AI 学习路径推荐

**目标**：雏英个人中心展示「推荐下一步」，基于已学内容推荐未报名的课程/活动。

**实现方案**：
- 后端：`GET /api/me/recommendations` — 查询 eagle 未报名的课程/活动 → 调 DeepSeek 根据已学内容推荐 3 项
- DeepSeek prompt：传入已报名列表 + 积分记录 + 可用课程/活动列表 → 返回 `[{id, type:"course"|"activity", reason}]`
- 前端：MeOverviewPage「学习推荐」卡片展示推荐列表，可点击跳转
- 降级：DeepSeek 不可用时，按简单的"选未报名的热门项"规则推荐

**改动文件**：`server/src/routes/pointApps.ts`（+1 路由）、`MeOverviewPage.tsx`（+推荐卡片）

---

### 8.3 雏英学习画像

**目标**：雏英个人中心展示能力雷达图 + 成长时间线，让雏英看到自己的成长轨迹。

**实现方案**：
- **能力雷达图**：基于积分类型分布画 SVG 五边形雷达图
  - 五个维度对应五种积分模板：比赛获奖/分享宣讲/项目贡献/荣誉表彰/其他专项
  - 每维度分值 = 该类型累计获得的积分 / 该类型目标积分 × 100
- **成长时间线**：按时间列出关键里程碑（加入计划、首次报名、首次提交心得、首次获得积分、积分突破 100/500/1000）
- 前端组件：`EagleProfile.tsx`（雷达图 SVG + 时间线 + 统计卡片）
- 后端：`GET /api/me/profile` — 聚合学习数据

**改动文件**：`server/src/routes/pointApps.ts`（+1 路由）、`client/src/components/EagleProfile.tsx`（新建）、`MeOverviewPage.tsx`（引入）

---

### 8.4 演示数据 Seed 增强

**目标**：seed 增加已结束活动、样例报名/申请，方便当场演示完整链路。

**实现方案**：
- 在 `seed.ts` 中增加：
  - 2 个已结束活动（供演示 24h 窗口和心得申请）
  - 演示鹰报名上述活动 + 提交待审批的心得
  - 1 个待审批的加入申请
  - 1 个待审批的类型二专项申请
- 确保 `npm run dev` 首次启动即可走通完整 Demo 路径

**改动文件**：`server/src/seed.ts`
