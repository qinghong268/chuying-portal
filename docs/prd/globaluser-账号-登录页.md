## 1. 页面概述

### 1.1 基本信息

| 属性 | 说明 |
| --- | --- |
| 页面路由 | `/login` |
| 适用角色 | 未登录用户；已登录访问时按角色重定向离开 |
| 页面目的 | 完成身份认证；**V1 以演示一键三角色登录为主**，可附简单账号密码占位；登录后按角色分流前台个人中心或后台 |
| 页面类型 | 独立认证页（可简化顶栏：仅 Logo + 回首页；无完整前台导航亦可） |
| 适配终端 | PC Web；Chrome 90+ / Edge 90+ |
| 入口 | 顶栏「登录」；访问需登录页时的 `redirect` 跳转 |

### 1.2 核心功能（动词短语）

| 功能点 | 类型 | 优先级 | 描述 |
| --- | --- | --- | --- |
| 演示一键登录（三角色） | 新增 | P0 | 一键切换：雏鹰 / 管理员 / 超级管理员 |
| 账号密码登录（占位） | 新增 | P1 | 简单邮箱/账号 + 密码表单，便于后续替换正式登录 |
| 登录后按角色分流 | 新增 | P0 | 雏鹰 → 前台个人中心；管理员/超管 → `/admin` |
| 携带 redirect 回跳 | 新增 | P0 | 尊重安全的 `redirect` 查询参数 |

### 1.3 功能关系（逻辑层级）

```
账号与身份
├── 演示一键登录 [平级] ← V1 主路径
├── 账号密码登录 [平级] ← 占位，可后续替换
├── 登录后分流 [include：登录成功必然涉及]
└── 登出 [平级]（入口在顶栏/后台，不在本页）
```

### 1.4 业务硬规则（登录分流）

| 角色 | 登录成功默认着陆 |
| --- | --- |
| 雏鹰（eagle） | 前台个人中心 `/me`；若存在合法 `redirect` 则优先回跳前台目标 |
| 管理员（admin） | `/admin` |
| 超级管理员（super_admin） | `/admin` |

补充规则（与 `globaluser.md` §6 一致）：

- 访客访问需登录页 → 跳转 `/login?redirect=`。  
- 雏鹰访问 `/admin/*` → 拒绝并提示无权限（不在本页处理，但演示账号不得误分流）。  
- V1 **不做真实企业 SSO**；正式登录方式（手机号/邮箱/企业微信等）为 `[待决]`。

### 1.5 本页不做

- 不做注册完整流程（加入走 F07）。  
- 不做 OAuth/SSO 真接入。  
- 不做移动端适配。  
- 不做找回密码完整闭环（可放「占位链接」`[待补充]`）。

## 3. 区域说明与交互

### 3.1 演示一键三角色（P0 主路径）

| 卡片 | 角色 | 成功后跳转 |
| --- | --- | --- |
| 雏鹰 | `eagle` | `/me` 或合法 `redirect`（仅允许前台路径） |
| 管理员 | `admin` | `/admin`（忽略会把管理员带去前台个人能力的 redirect，或仅允许 `/admin` 前缀） |
| 超级管理员 | `super_admin` | `/admin` |

交互：

1. 点击卡片立即请求演示登录接口（或等价种子会话），按钮进入 Loading。  
2. 成功后写入会话（Session/JWT，实现自定），再路由分流。  
3. 失败 Toast「演示登录失败，请重试」。  
4. 三张卡片视觉并列，文案明确「演示」以免误解为生产自助开户。

### 3.2 账号密码占位（P1）

| 元素 | 规则 |
| --- | --- |
| 账号 | 文本；trim；非空 |
| 密码 | password；可切换可见性；非空 |
| 登录按钮 | 提交占位接口；成功后按返回角色走同一套分流 |
| 种子账号 | 文档/种子数据提供三角色示例账号 `[待补充]` 具体字符串；可与一键登录同一批用户 |

占位目的：方便后续替换正式登录，**不得**在 V1 文档中承诺 SSO 已就绪。

### 3.3 redirect 安全规则

| 规则 | 说明 |
| --- | --- |
| 允许 | 站内相对路径，如 `/activities/123`、`/me/enrollments` |
| 拒绝 | 外链、`//evil.com`、`javascript:` 等；拒绝时回落默认着陆 |
| 角色冲突 | 管理员/超管携带前台 `redirect` 时：默认仍进 `/admin`；是否尊重前台 redirect `[待补充]`（建议 V1：管理端角色固定 `/admin`） |
| 雏鹰携带 `/admin` redirect | 忽略并进 `/me`，避免无权限死循环 |

### 3.4 已登录访问 `/login`

| 当前角色 | 行为 |
| --- | --- |
| 雏鹰 | 重定向 `/me` 或 redirect |
| 管理员/超管 | 重定向 `/admin` |

### 3.5 空 / 错 / 加载

| 状态 | 表现 |
| --- | --- |
| 一键/表单提交中 | 对应按钮 Loading，禁用其它登录入口防双提交 |
| 账号或密码错误 | 表单区错误「账号或密码不正确」（不暴露具体字段） |
| 账号停用 | 「账号已停用，请联系管理员」 |
| session 过期进入 | 可选查询参数 `?expired=1`，顶部提示「登录已过期，请重新登录」`[待补充]` |

## 4. 关键字段与校验

### 4.1 账号密码表单

| 字段 | 必填 | 校验 |
| --- | --- | --- |
| `account` | 是 | 非空；最长 128；trim |
| `password` | 是 | 非空；最长 128 |

### 4.2 演示登录请求

| 字段 | 说明 |
| --- | --- |
| `demoRole` | 枚举：`eagle` / `admin` / `super_admin` |

### 4.3 登录成功会话需含

| 字段 | 说明 |
| --- | --- |
| `userId` | 用户 ID |
| `displayName` | 展示名 |
| `role` | eagle / admin / super_admin |
| `permissionPackages` | 管理端角色的权限包列表（雏鹰可空） |

## 5. 主流程 / 分支 / 异常

### 5.1 主流程 — 演示一键登录（雏鹰）

1. 用户打开 `/login`。  
2. 点击「雏鹰 · 一键登录」。  
3. 系统建立雏鹰会话。  
4. 跳转 `/me`（或合法前台 redirect）。

### 5.2 主流程 — 演示一键登录（管理员/超管）

1. 点击「管理员」或「超级管理员」一键登录。  
2. 系统建立对应会话与权限包。  
3. 跳转 `/admin`。

### 5.3 主流程 — 账号密码占位

1. 输入种子账号与密码 → 登录。  
2. 按返回 `role` 执行与 §1.4 相同分流。

### 5.4 分支流程

| 分支 | 行为 |
| --- | --- |
| 从活动详情 redirect 来 | 雏鹰登录后回到该详情以便报名 |
| 点击「申请加入」 | 跳转 `/join`，不建立会话 |
| 返回首页 | 跳转 `/` |

### 5.5 异常流程

| 异常 | 反馈 |
| --- | --- |
| 演示接口失败 | Toast + 可再点 |
| 密码错误 | 表单级错误文案 |
| 非法 redirect | 静默忽略，走默认着陆 |

| 方法 | 路径意图 | 说明 |

## 7. 验收要点（AC）

1. 页面同时提供三个演示入口：雏鹰、管理员、超级管理员。  
2. 点击「雏鹰」一键登录成功后进入 **`/me`**（无 redirect 时）。  
3. 点击「管理员」或「超级管理员」一键登录成功后进入 **`/admin`**。  
4. 未登录访问需登录资源（如 `/me`）会跳到 `/login?redirect=...`；雏鹰登录后回到原前台路径。  
5. 管理员/超管登录不被前台 redirect 误送到无权限的雏鹰能力页（V1：固定 `/admin`）。  
6. 账号密码占位：空账号/空密码不可提交；错误凭证有明确失败提示。  
7. 已登录用户再次打开 `/login` 会按角色离开登录页，不停留空白表单。  
8. 提供「申请加入」入口至 `/join`。  
9. PC 1366×768 下品牌区与登录区同时可见；无移动端适配要求。  
10. 文案标明演示登录，避免被理解为生产自助注册。
