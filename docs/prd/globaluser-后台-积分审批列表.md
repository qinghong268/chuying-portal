## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A09 |
| 页面名称 | 积分审批列表 |
| 页面路由 | `/admin/point-apps` |
| 权限包 | `point_review`（无权限：侧栏不展示；直链进无权限页） |
| 适用角色 | 已授予 `point_review` 的管理员；超级管理员 |
| 页面目的 | 集中查看积分申请队列，按状态/类型筛选，进入详情完成审批 |
| 页面类型 | 后台表格列表（跳转详情审批，本页不做行内通过/驳回） |
| 前置条件 | 已登录且持有 `point_review` |

### 1.1 业务背景

雏鹰提交类型一（活动完成心得）或类型二（专项模板）申请后进入「待审批」。审批员需在队列中快速定位待办，并进入详情核对 payload 后决策。本页只负责任务分发与检索；写流水与驳回原因在 A10 完成。

## 3. 区域说明与交互

| 区域 | 规则 |
| --- | --- |
| 摘要条 | 展示待审批数、今日通过/驳回数；失败时显示「—」；数字可标 `[待核实]` 刷新频率（建议进入页拉取） |
| Tab | 默认「待审批」；切换重置到第 1 页；与状态筛选互斥（Tab 即状态） |
| 类型筛选 | 全部 / 类型一（活动完成心得）/ 类型二（专项） |
| 模板筛选 | 仅类型二或全部时可用；选项为预置五模板 + 全部；类型一时禁用 |
| 关键词 | 匹配申请人姓名/学号或工号（字段以用户模型为准）/ 申请号 / 事项摘要 |
| 时间范围 | 按提交时间；默认近 30 天或不限 `[待核实]`，文档暂定不限 |
| 行操作 | 「详情」→ `/admin/point-apps/:id` |
| 行点击 | 整行可点进详情（与按钮一致） |
| 摘要列 | 类型一：活动标题截断；类型二：`模板名 · 具体事项` 截断，hover 全量 |
| 申请分值 | 展示申请人提交时的申请分值（类型二=模板默认分值；类型一=活动目标积分或配置分） |
| 加载/空/错 | 骨架屏；空：「暂无申请」或「无匹配结果」+ 清空筛选；错：可重试 |

## 4. 关键字段与校验（列表展示）

| 列 | 说明 |
| --- | --- |
| 申请号 | 系统生成业务号或短 id |
| 申请人 | 雏鹰显示名 + 次要标识（邮箱/工号，有则显示） |
| 类型 | 类型一 / 类型二 |
| 摘要 | 见上 |
| 申请分值 | 数字 |
| 状态 | 待审批 / 已通过 / 已驳回 |
| 提交时间 | `YYYY-MM-DD HH:mm` |
| 操作 | 详情 |

本页无表单提交校验；筛选条件非法（结束早于开始）时前端拦截并提示。

## 5. 主流程 / 分支 / 异常

### 5.1 主流程：处理待办

1. 审批员打开 `/admin/point-apps`，默认 Tab「待审批」。  
2. 系统返回分页列表。  
3. 审批员按类型/关键词定位目标行 → 点「详情」。  
4. 进入 A10 完成通过或驳回后返回本页，列表刷新，该单离开「待审批」。

### 5.2 分支

| 分支 | 行为 |
| --- | --- |
| 查看历史 | 切「已通过」「已驳回」「全部」只读浏览 |
| 类型二按模板筛 | 选择 `contest_award` 等缩小队列 |
| 从控制台待办跳入 | 可带 `?status=pending` 深链，落地待审批 Tab |

### 5.3 异常

| 场景 | 处理 |
| --- | --- |
| 列表接口失败 | 错误区 + 重试 |
| 详情 id 已删 | 进详情后由 A10 处理 404 |
| 无权限 | 无权限页 / 403 |

## 6. 接口依赖摘要

| 意图 | 方法 | 路径（示意） |
| --- | --- | --- |
| 审批队列列表 | GET | `/api/admin/point-applications?status=&type=&templateCode=&q=&from=&to=&page=&pageSize=` |
| 队列摘要计数 | GET | `/api/admin/point-applications/summary` |

列表项至少含：`id`, `applicationNo`, `applicant`, `type`（`activity_review` / `special` 或等价）, `summary`, `requestedPoints`, `status`, `submittedAt`, `templateCode?`。

---

## 7. 验收要点（AC）

1. 仅 `point_review`（或超管）可访问；无权限直链为无权限页。  
2. 默认展示待审批列表；Tab 与分页行为正确。  
3. 类型一、类型二在「类型」列与「摘要」列展示规则不同且可读。  
4. 点击「详情」进入 `/admin/point-apps/:id`。  
5. 筛选（类型、模板、关键词、时间）生效；空结果有引导。  
6. 加载失败可重试；本页不出现「通过/驳回」写操作按钮。
