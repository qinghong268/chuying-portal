## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | A05 |
| 页面名称 | 活动管理列表 |
| 页面路由 | `/admin/activities` |
| 页面类型 | 管理后台列表页（PC 表格） |
| 适用角色 | 管理员、超级管理员 |
| 所需权限包 | `activity`（活动管理） |
| 页面目的 | 运营人员检索、查看活动，进入新建/编辑，并跳转报名名单（含线上进度查看入口） |
| 前置条件 | 已登录管理端且持有 `activity` |

活动实体关键属性：形态 `online` / `offline`、开始/结束时间、**积分申请通道截止**、目标积分、发布状态。报名截止不单独列表展示（语义=开始时间）。

## 3. 区域说明与交互

| 区域 | 说明与交互 |
| --- | --- |
| 新建活动 | 跳转 `/admin/activities/new`（A06） |
| 编辑 | 跳转 `/admin/activities/:id/edit`（A06） |
| 报名名单 | 跳转 `/admin/activities/:id/enrollments`（A07）；线上活动在该页可查看观看进度 |
| 形态列 | 文案「线上」「线下」；线下报名截止列显示「—」（线下规则为开始前可报名，无单独截止字段或字段为空） |
| 上架/下架 | 二次确认；下架后前台不可报名；已有报名保留 |
| 状态 | draft / published / ended（ended 可由结束时间自动推导或运营手动，实现二选一须在接口层钉死）`[待补充]` |
| 加载/空/错 | 骨架屏；「暂无活动」+ CTA「新建活动」；失败可重试 |

## 4. 关键字段与校验

列表展示字段：

| 字段 | 说明 |
| --- | --- |
| title | 活动标题 |
| form | `online` \| `offline` |
| startAt / endAt | 活动开始、结束 |
| enrollDeadline | 线上报名截止；线下显示「—」 |
| targetPoints | 目标积分（类型一入账参考） |
| status | 草稿/已发布/已结束等 |
| enrollmentCount | 已报名人数 |

筛选：形态、状态、标题关键词；无额外提交校验除时间类无。

---

## 5. 主流程 / 分支 / 异常

**主流程**：进入列表 → 筛选 → 新建或编辑 → 发布 → 查看报名名单。

**分支流程**：下架已发布活动；从名单返回列表保持分页。

**异常流程**：无 `activity` → 无权限页；下架失败 Toast；删除若 V1 不做则不展示删除按钮（推荐 V1：仅下架，不做物理删除）。

---

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/activities` | 分页列表；form、status、q |
| POST | `/api/admin/activities/:id/publish` | 上架/发布 |
| POST | `/api/admin/activities/:id/unpublish` | 下架 |

---

## 7. 验收要点（AC）

1. 仅 `activity`（或超管）可访问；直链无权限页正确。  
2. 列表展示形态、开始/结束、线上报名截止、目标积分。  
3. 线下活动报名截止列不误显示虚假截止时间。  
4. 「新建」「编辑」「报名名单」路由正确。  
5. 下架需二次确认，确认后前台不可再报名。
