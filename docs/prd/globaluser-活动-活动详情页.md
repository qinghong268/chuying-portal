## 1. 页面概述

### 1.1 基本信息

| 属性 | 说明 |
| --- | --- |
| 页面路由 | `/activities/:id` |
| 适用角色 | 访客（只读）；雏英（报名 / 查看进度 / 申请心得入口）；管理端角色仅可浏览公开信息 |
| 页面目的 | 展示活动完整信息；在开始前完成报名；活动结束后在窗口内引导发起「活动完成心得」（类型一，跳转 F13） |
| 页面类型 | 前台公开详情（顶栏 + 页脚壳） |
| 适配终端 | PC Web；Chrome 90+ / Edge 90+ |
| 入口 | F03 活动列表卡片；个人中心「我的报名」回跳；站外分享链接 |

### 1.2 核心功能（动词短语）

| 功能点 | 类型 | 优先级 | 描述 |
| --- | --- | --- | --- |
| 浏览活动详情 | 新增 | P0 | 展示标题、形态、时间、目标积分、积分申请通道截止、正文、规则摘要 |
| 报名活动 | 新增 | P0 | 雏英在开始前提交报名，生成「已报名」记录 |
| 查看/更新线上观看进度 | 新增 | P1 | 已报名且线上活动时可展示与演示更新进度（**不作为**心得门槛） |
| 申请活动完成心得入口 | 新增 | P0 | 活动结束后满足窗口时跳转 F13，并预填绑定活动 |

### 1.3 功能关系（逻辑层级）

```
活动运营
├── 浏览活动详情 [平级] ← 本页
├── 报名活动 [平级]
├── 查看线上观看进度 [平级]
└── 申请活动完成心得 [扩展] → 跳转 F13（发起积分申请）
```

报名与申请心得为**平级**能力；心得入口是在详情页的 **extend** 引导，正式提交在 F13。

### 1.4 业务硬规则（与总览 §5.5 / 代码一致）

#### 1.4.1 报名窗口

| 活动形态 | 可报名条件 |
| --- | --- |
| 线上（online） | **活动开始前**：`now < startAt` |
| 线下（offline） | **活动开始前**：`now < startAt` |

说明：报名截止语义等于开始时间；**无独立报名截止配置项**。报名成功后状态为「已报名」。V1 不做「报名即自动加分」。

#### 1.4.2 活动完成心得（类型一）申请门槛

**共性前置**：当前用户存在该活动的成功报名记录。

| 条件 | 说明 |
| --- | --- |
| 时间窗 | 活动已结束，且 `now` 处于 **endAt + 24h** 内 |
| 通道截止 | 若配置了 `pointApplyDeadline`，则还须 `now ≤ pointApplyDeadline`（与 24h 取更严） |
| 进度 | **不要求**观看进度 ≥99%（与课程不同） |

#### 1.4.3 心得正文约束（在 F13 落地，本页须文案对齐）

- 心得正文字数：**300–1000 字**。  
- 申请入口：`/me/applications/new?activityId=`（类型一锁定）。

## 3. 区域说明与交互

### 3.1 信息主区

| 区域 | 规则 |
| --- | --- |
| 面包屑 | 「活动」链回 `/activities`；当前页为标题文本 |
| 封面 | 已发布封面；无则占位 |
| 标题与标签 | 形态标签 + 状态标签（算法同 F03） |
| 元信息 | 开始/结束时间；线下展示地点；可选目标积分 `[待补充]` 是否展示 |
| 正文 | CMS/后台录入的富文本；仅已发布内容 |
| 规则摘要 | 固定展示线上/线下报名与心得门槛文案，与 §1.4 一致，禁止与常量冲突 |

### 3.2 操作侧栏 — 按钮状态机

以下按**优先级从高到低**判断，命中即停。

#### A. 报名主按钮

| 条件 | 按钮/表现 |
| --- | --- |
| 活动不存在或未发布 | 整页「活动不存在或已下架」，无操作按钮 |
| 未登录 | 主按钮「去登录」→ `/login?redirect=/activities/:id` |
| 已登录但非雏英（如管理端演示号在前台） | 提示「请使用雏英账号报名」；按钮禁用或隐藏写操作 |
| 已报名 | 主按钮文案改为「已报名」并禁用；可展示报名时间 |
| 线上且当前时间 ≥ `enrollDeadlineAt` | 「报名已截止」禁用 |
| 线下且当前时间 ≥ `startAt` | 「报名已截止（须在开始前报名）」禁用 |
| 名额已满 | 「名额已满」禁用；是否候补 `[待补充]` |
| 其余可报名窗口 | 「立即报名」可点 → 二次确认 → 提交 |

#### B. 「申请活动完成心得」按钮

| 条件 | 表现 |
| --- | --- |
| 未登录 / 非雏英 | 不展示或置灰并提示先登录/使用雏英账号 |
| 未报名 | 隐藏或禁用，提示「请先报名本活动」 |
| 线上且进度 < 99% | 禁用；旁注「观看进度需达到 99%（当前 xx%）」 |
| 线上且进度 ≥ 99% | 可点 → 跳转 F13，预填类型一 + 本活动 |
| 线下且活动未结束 | 禁用；旁注「活动结束后 24 小时内可申请」 |
| 线下且已结束但超过 `endAt + 24h` | 禁用；旁注「申请窗口已关闭」 |
| 线下且 `endAt ≤ now ≤ endAt + 24h` | 可点 → 跳转 F13 |
| 已有进行中/已通过的类型一申请 | 按钮文案改为「查看我的申请」→ F11/F14；是否只允许通过一次见 `[待决]` |

### 3.3 线上进度区

| 元素 | 规则 |
| --- | --- |
| 进度条/百分比 | 仅 `mode=online` 且已报名时展示；取值 `WatchProgress.percent`（0–100） |
| 播放器 | 嵌入方式 `[待补充]`；进度上报失败 Toast「进度同步失败，请重试」 |
| 刷新 | 提供「刷新进度」；刷新后重新评估心得按钮 |

### 3.4 空 / 错 / 加载

| 状态 | 表现 |
| --- | --- |
| 加载 | 主区 + 侧栏骨架屏 |
| 404 / 未发布 | 「活动不存在或已下架」+ 「返回活动列表」 |
| 报名失败 | Toast 展示后端原因（已报名、已截止、无权限等） |
| 详情接口失败 | Toast + 重试 |

## 4. 关键字段与校验

### 4.1 详情字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 路径参数 |
| `title` | 是 | 标题 |
| `mode` | 是 | online / offline |
| `startAt` / `endAt` | 是 | 起止时间戳 |
| `enrollDeadlineAt` | 线上是 | 线上报名截止；线下可空 |
| `location` | 线下建议是 | 线下地点 |
| `coverUrl` | 否 | 封面 |
| `contentHtml` | 是 | 介绍正文 |
| `targetPoints` | 否 | 目标积分展示 `[待补充]` |
| `enrollment` | 登录时 | 当前用户报名状态与时间 |
| `watchProgressPercent` | 线上已报名 | 0–100 |
| `reflectionEligibility` | 建议后端下发 | `{ eligible: boolean, reasonCode: string }` 避免前后端门槛不一致 |

### 4.2 报名请求

| 字段 | 校验 |
| --- | --- |
| `activityId` | 必填，且活动已发布 |
| 用户身份 | 必须为雏英；未登录拒绝 |
| 窗口 | 线上：`now < enrollDeadlineAt`；线下：`now < startAt` |
| 重复报名 | 已存在成功报名则拒绝 |

### 4.3 心得入口跳转参数（建议）

| 参数 | 说明 |
| --- | --- |
| `type` | `activity_reflection`（类型一） |
| `activityId` | 当前活动 ID |

F13 须二次校验门槛与 300–400 字；本页仅做入口与前置提示。

## 5. 主流程 / 分支 / 异常

### 5.1 主流程 — 浏览与报名

1. 用户从列表进入 `/activities/:id`。  
2. 系统拉取详情；若已登录则附带报名态与进度。  
3. 雏英在窗口内点击「立即报名」→ 确认弹层展示活动名与时间 → 确认。  
4. 系统写入报名记录（已报名）→ Toast「报名成功」→ 侧栏切换为已报名态。

### 5.2 主流程 — 线上完成并申请心得

1. 已报名雏英观看线上内容，进度上报至 ≥99%。  
2. 侧栏「申请活动完成心得」可点。  
3. 跳转 F13，预填类型一与活动绑定。  
4. 用户在 F13 填写 300–400 字心得并提交（本页不采集正文）。

### 5.3 主流程 — 线下完成并申请心得

1. 已报名雏英在活动结束后、`endAt + 24h` 内打开详情。  
2. 「申请活动完成心得」可点并跳转 F13。  
3. 超时后按钮禁用并提示窗口关闭。

### 5.4 分支流程

| 分支 | 行为 |
| --- | --- |
| 访客点报名 | 跳转登录，带 redirect 回本页 |
| 已报名再次进入 | 展示已报名；线上展示进度 |
| 管理端账号 | 可阅读详情，不可报名/申请心得 |

### 5.5 异常流程

| 异常 | 反馈 |
| --- | --- |
| 报名窗口外提交 | 拒绝；文案区分线上截止 / 线下须开始前 |
| 进度未达标点击心得（前端被绕过） | 后端拒绝；Toast 说明需 ≥99% |
| 线下超 24h 申请 | 后端拒绝；提示窗口已关闭 |
| 无报名记录申请心得 | 后端拒绝 |

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/activities/:id` | 活动详情；登录态附带 enrollment / progress / eligibility |
| POST | `/api/activities/:id/enrollments` | 报名；校验形态对应窗口与身份 |
| GET | `/api/activities/:id/watch-progress` | 查询当前用户观看进度（线上） |
| PUT/POST | `/api/activities/:id/watch-progress` | 上报进度 percent 0–100 `[待补充]` 协议 |
| — | 跳转 F13 | 前端路由，不在本页提交积分申请 |

## 7. 验收要点（AC）

1. 已发布活动详情完整展示标题、形态、时间与正文；未发布/不存在显示下架态。  
2. **线上**：当前时间早于报名截止时可报名；截止后「立即报名」不可用。  
3. **线下**：当前时间早于开始时间可报名；开始后不可报名。  
4. 未登录点击报名跳转 `/login?redirect=` 回本详情。  
5. 非雏英账号不可成功报名（前端禁用 + 后端拒绝）。  
6. 重复报名被拒绝，侧栏保持「已报名」。  
7. **线上**：进度展示正确；进度 <99% 时「申请活动完成心得」不可用；≥99% 可跳转 F13。  
8. **线下**：未结束或超过 `endAt+24h` 时心得入口不可用；窗口内可跳转 F13。  
9. 规则摘要文案写明：线上截止前报名、进度≥99%申请；线下开始前报名、结束后 24h 内申请；心得 300–400 字。  
10. 接口失败有 Toast 与可重试；报名确认有二次确认弹层。  
11. PC 1366×768 下信息区与操作侧栏同时可见，无移动端适配要求。
