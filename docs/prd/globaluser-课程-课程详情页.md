## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | F06 |
| 页面名称 | 课程详情页 |
| 页面路由 | `/courses/:id` |
| 所属模块 | 课程 |
| 页面类型 | 前台浏览页（公开，无需登录） |
| 适用角色 | 访客、雏鹰；管理员/超管可浏览公开内容 |
| 页面目的 | 展示单门已发布课程的详情与学习入口说明；若配置了可选 `activityId`，提供前往关联活动的入口以便与活动进度联动 |
| 前置条件 | `id` 对应已发布课程；否则 404/不可用态 |
| 终端规格 | PC Web；Chrome 90+ / Edge 90+；**1366×768** 及以上；V1 不做移动端适配 |

### 1.1 与活动进度的可选联动

| 项 | 说明 |
| --- | --- |
| 可选字段 | `activityId`：课程挂接某活动时用于跳转活动详情 |
| 进度阈值 | 全站线上观看进度阈值仍为 **99%**（见 `globaluser.md` 常量）；**进度本身在活动域维护**（`WatchProgress`），本页不重复实现进度条业务，除非产品确认课程播放器与活动共用进度源 `[待补充]` |
| 本页 V1 默认 | 详情浏览 + 大纲/介绍占位 +「前往关联活动」；完整播放器与进度上报协议标 `[待补充]` |
| 内容原则 | 不编造真实课程正文；用占位字段与运营配置内容 |

## 3. 区域说明与交互

### 3.1 面包屑与导航

| 项 | 说明 |
| --- | --- |
| 面包屑「课程」 | 回 `/courses` |
| 顶栏 | 「课程」高亮 |

### 3.2 标题信息区

| 项 | 说明 |
| --- | --- |
| 字段 | `title`、`category`、`durationLabel`、`summary`、`coverUrl` |
| 开始学习 | V1：若暂无独立播放能力，可滚动至大纲首章或 Toast「学习能力即将开放」`[待补充：最终行为]`；若已挂播放器则在媒体区播放 |
| 前往关联活动 | 仅当 `activityId` 有值；跳转 `/activities/:activityId` |
| 加载 | 详情骨架（媒体块 + 标题条 + 正文灰条） |

### 3.3 介绍与大纲

| 项 | 说明 |
| --- | --- |
| 介绍 | 富文本 `bodyHtml`；消毒同计划介绍页 |
| 大纲 | `outline[]`：`chapterTitle`、`chapterSummary?`、`order`；可空则隐藏大纲块 |
| 章节点击 | V1 默认仅展开摘要或无操作；若后续接课时播放再扩展 `[待补充]` |

### 3.4 空/错/不可用

| 状态 | 表现 |
| --- | --- |
| 课程不存在或未发布 | 整页「课程不存在或已下架」+「返回课程列表」 |
| 接口失败 | Toast + 重试 |
| 关联活动无效 | 隐藏「前往关联活动」或点击提示不可用 |

## 4. 关键字段与校验

本页**无用户提交表单**（浏览态）。路径与展示字段：

| 字段 | 类型 | 校验/约束 | 说明 |
| --- | --- | --- | --- |
| id（路径） | string | 必填；非法/不存在 → 不可用态 | 课程 ID |
| title | string | 非空 | 标题 |
| coverUrl | string | URL | 封面 |
| summary | string | 可空 | 摘要 |
| category | string | 可空 | 分类占位 |
| durationLabel | string | 可空 | 时长占位 |
| bodyHtml | string | 可空 | 介绍富文本 |
| outline[] | array | 可空 | 章节占位列表 |
| activityId | string \| null | **可选关联** | 有则展示活动入口 |
| status | enum | 须为 `published` 才展示详情 | 与列表一致 |

与全站常量一致性：若本页未来展示「可申请积分」类文案，须引用活动侧规则（线上进度 **≥99%**、线下结束 **+24 小时**、心得 **300–400** 字），**不得**另造阈值。

## 5. 处理流程

### 5.1 主流程

1. 用户自列表进入 `/courses/:id`。  
2. 系统按 id 拉取已发布详情。  
3. 渲染封面/信息/介绍/大纲。  
4. 用户阅读；可选点击「前往关联活动」进入活动详情。

### 5.2 分支流程

| 分支 | 行为 |
| --- | --- |
| 点击返回列表 / 面包屑 | 回 `/courses` |
| 有 `activityId` | 展示并允许跳转活动详情 |
| 无 `activityId` | 不展示关联活动按钮 |
| 已登录雏鹰从活动回流 | 正常打开课程详情（无额外权限墙） |

### 5.3 异常流程

| 异常 | 处理 |
| --- | --- |
| 404 / 未发布 | 不可用态 + 返回列表 |
| 网络/5xx | Toast + 重试 |
| 富文本或封面失败 | 局部降级，其余可读 |

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/courses/:id` | 已发布课程详情（含可选 `activityId`、outline、body） |
| GET | （可选）`/api/activities/:activityId` | 校验关联活动是否仍可跳转；亦可仅前端跳转由活动页自处理 |

写操作：V1 本页默认无；若后续播放器上报进度，应写入活动进度接口（如 `WatchProgress`），协议 `[待补充]`，且阈值仍用全站 **99%**。

---

## 7. 验收要点（AC）

1. **AC-F06-01** 已发布课程可通过 `/courses/:id` 未登录访问并看到标题与介绍区。  
2. **AC-F06-02** 未发布或不存在 id 显示不可用态，并可返回 `/courses`。  
3. **AC-F06-03** 存在 `activityId` 时显示「前往关联活动」且跳转 `/activities/:activityId`；无则不显示该按钮。  
4. **AC-F06-04** 大纲无数据时不展示空大纲标题块。  
5. **AC-F06-05** 接口失败可重试；页面不白屏。  
6. **AC-F06-06** 任何积分/进度说明若出现，须与全站常量（99%、+24h、300–400 字）一致，无冲突文案。  
7. **AC-F06-07** 1366×768 下双栏或堆叠布局完整可读，无横向溢出。
