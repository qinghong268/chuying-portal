## 1. 页面概述

| 属性 | 说明 |
| --- | --- |
| 页面编号 | F05 |
| 页面名称 | 课程列表页 |
| 页面路由 | `/courses` |
| 所属模块 | 课程 |
| 页面类型 | 前台浏览页（公开，无需登录） |
| 适用角色 | 访客、雏鹰；管理员/超管可浏览公开内容 |
| 页面目的 | 展示已发布课程的可浏览清单，支持进入课程详情；若课程关联活动进度，仅作可选标识，不在本页完成报名/申请 |
| 前置条件 | 可访问前台 |
| 终端规格 | PC Web；Chrome 90+ / Edge 90+；**1366×768** 及以上；V1 不做移动端适配 |

### 1.1 与活动的关系

| 项 | 说明 |
| --- | --- |
| 可选关联 | 课程可配置 `activityId`（可选）。有值时，列表项可展示「关联活动」弱提示或入口 |
| 本页不做 | 活动报名、观看进度上报、积分申请（分别在活动/个人中心流程） |
| 内容原则 | **禁止编造真实课程名录**；字段用占位；示例数据由种子/运营配置 |

## 3. 区域说明与交互

### 3.1 顶栏

「课程」导航高亮；其余同全站前台壳。

### 3.2 筛选与搜索（若 V1 启用）

| 控件 | 行为 |
| --- | --- |
| 分类 | 下拉；选项来自已发布课程的分类枚举；「全部」为默认 |
| 关键词 | 按标题/摘要模糊匹配（前后端约定） |
| 查询 | 重置到第 1 页并刷新列表 |
| 未实现筛选时 | 隐藏筛选区，仅展示全部已发布课程分页列表 |

分类枚举与搜索规则标 `[待补充]`。

### 3.3 课程卡片

| 项 | 说明 |
| --- | --- |
| 点击热区 | 整卡或「查看详情」→ `/courses/:id` |
| 展示字段 | 封面、标题、摘要（单行省略）、分类占位、时长占位 |
| 可选关联 | 若存在 `activityId`：展示文案「关联活动」；点击可进 `/activities/:activityId`（次级链接，不阻断进详情） |
| 加载 | 卡片骨架网格 |
| 空状态 | 「暂无课程」+ 引导「查看活动」→ `/activities` 或「返回首页」 |
| 错误态 | Toast + 重试 |

### 3.4 分页

页码切换保持当前筛选条件；非法页码回退第 1 页。

## 4. 关键字段与校验

### 4.1 列表项展示字段（占位模型）

| 字段 | 类型 | 校验/约束 | 说明 |
| --- | --- | --- | --- |
| id | string | 必有 | 路由参数 |
| title | string | 非空 | 课程标题（运营配置） |
| coverUrl | string | URL；失败用默认封面 | 封面 |
| summary | string | 可空；列表截断 | 摘要 |
| category | string | 可空 | 分类占位 `[待补充]` |
| durationLabel | string | 可空 | 如「约 N 学时」占位，不编造具体课表 |
| activityId | string \| null | **可选** | 关联活动 ID；无则不展示关联入口 |
| status | enum | 前台仅 `published` | 发布状态 |
| publishedAt | datetime | 可展示/可排序 `[待补充]` | 发布时间 |

### 4.2 筛选输入（若启用）

| 字段 | 校验 |
| --- | --- |
| keyword | 最长 `[待补充]` 字符；去首尾空格；空则忽略 |
| category | 须为已知选项或「全部」 |

本页无写库表单。

## 5. 处理流程

### 5.1 主流程

1. 用户打开 `/courses`。  
2. 系统请求已发布课程分页列表。  
3. 渲染卡片；用户点击某课进入 `/courses/:id`。

### 5.2 分支流程

| 分支 | 行为 |
| --- | --- |
| 使用筛选/搜索 | 带查询参数刷新列表 |
| 点击「关联活动」 | 进入对应活动详情（需 `activityId` 有效） |
| 分页 | 请求对应 page |

### 5.3 异常流程

| 异常 | 处理 |
| --- | --- |
| 列表接口失败 | Toast + 重试 |
| 关联活动已下架/不存在 | 隐藏关联入口或点击后提示「活动不可用」并留在列表 |
| 无已发布课程 | 空状态 |

## 6. 接口依赖摘要

| 方法 | 路径意图 | 说明 |
| --- | --- | --- |
| GET | `/api/courses?page=&pageSize=&keyword=&category=` | 已发布课程列表 |
| GET | （可选）`/api/course-categories` | 筛选选项 |

响应列表项须能带上可选字段 `activityId`。写操作：无。

## 7. 验收要点（AC）

1. **AC-F05-01** `/courses` 未登录可访问；「课程」导航高亮。  
2. **AC-F05-02** 仅列出 `published` 课程；草稿不可见。  
3. **AC-F05-03** 点击卡片进入 `/courses/:id`。  
4. **AC-F05-04** 存在 `activityId` 时可看到关联活动入口；无该字段则不展示关联 UI。  
5. **AC-F05-05** 空列表与接口失败分别有空状态/重试，不白屏。  
6. **AC-F05-06** 1366×768 下栅格不横向溢出；分页可用。
