## 1. 目标与非目标

### 1.1 目标

建设 SoftTong「雏鹰计划」对外宣传与对内运营一体的 Web 系统：

1. **访客**可浏览品牌内容、活动与课程信息；
2. **雏鹰**可注册/登录、报名活动、提交积分申请、查看个人积分与申请进度；
3. **管理员 / 超级管理员**在独立后台完成内容运营、加入审核、活动管理、积分类型与审批、用户与权限、数据看板。

### 1.2 非目标（V1 不做）

- 移动端适配（仅 PC）
- 积分商城、排行榜、积分过期、报名即自动加分
- 真实企业 SSO（V1 可用演示一键登录；正式登录方式可后续替换）
- 原生 App / 小程序

## 4. 核心业务流程

### 4.1 加入雏鹰

1. 访客填写申请 → 状态「待审核」  
2. 拥有「加入审核」的管理员通过/驳回  
3. 通过后账号具备雏鹰身份（或激活已有账号）

### 4.2 活动报名

- **线上活动**：报名截止前可报名（具体截止字段由活动配置）。  
- **线下活动**：须在**活动开始前**完成报名。  
- 报名成功写入报名记录，状态「已报名」。

### 4.3 活动完成积分申请（类型一）

**前置（共性）**：存在成功报名记录。

| 活动形态 | 可申请条件 |
| --- | --- |
| 线上 | 观看进度 **≥ 99%** |
| 线下 | 活动已结束，且当前时间处于结束后的 **1 个自然日窗口**内（结束时刻起算 24 小时，或按自然日 00:00–23:59 需在实现前与产品再钉一句；**默认：结束时间戳 + 24 小时**） |

申请内容：

- 关联活动（系统强制绑定报名记录）  
- 心得正文：**300–400 字**  
- 提交后进入「待审批」；审批通过后按活动/类型配置入账积分

### 4.4 专项/比赛积分申请（类型二）

1. 选择**预置模板**（管理员在「积分类型」维护）  
2. 填写「具体事项」+「申请理由」  
3. 提交 → 审批 → 入账  

**V1 预置模板编码建议**：

| code | 名称 |
| --- | --- |
| `contest_award` | 比赛获奖 |
| `speech` | 分享宣讲 |
| `project_contrib` | 项目贡献 |
| `honor` | 荣誉表彰 |
| `other_special` | 其他专项 |

模板可配置：默认分值、是否启用、是否允许申请人改分值（V1 建议：申请人不可改，审批人可改最终分值）。

### 4.5 审批

- 通过：写积分流水，申请状态「已通过」  
- 驳回：必填驳回原因，状态「已驳回」  
- V1 暂定：驳回后是否可再提，见「待决」；未决前文档按「可对驳回单修改后重新提交为新版本/新单」预留

## 5. 数据模型（逻辑）

核心实体（后端落地用）：

- `User`（角色、状态）  
- `PermissionPackage` / `AdminGrant`  
- `JoinApplication`  
- `ContentBlock`（CMS）  
- `Activity`（形态 online/offline、时间、报名截止、目标积分、进度源等）  
- `Enrollment`  
- `WatchProgress`（userId + activityId，percent 0–100）  
- `PointTypeTemplate`  
- `PointApplication`（type、payload、status、reviewer、pointsGranted）  
- `PointLedger`（流水）  

进度阈值常量：`WATCH_PROGRESS_THRESHOLD = 99`  
线下申请窗口常量：`OFFLINE_APPLY_WINDOW_HOURS = 24`

## 6. 技术方向（可落地）

| 层 | 建议 |
| --- | --- |
| 前台 / 后台 | 同一仓库双入口（如 Vite React：`/` 前台、`/admin` 后台）或 monorepo 双 app |
| API | Node（Express/Fastify）或等价；REST JSON |
| 存储 | SQLite/PostgreSQL；文件上传本地或对象存储 |
| 鉴权 | Session/JWT；演示账号种子数据 |
| 进度 | 前端上报或播放器回调写入 `WatchProgress`（实现阶段定协议） |

本规格不锁定具体框架版本；实现计划阶段再拆任务。

## 9. 成功标准（V1）

- 访客可完整浏览 CMS 内容与活动/课程列表详情  
- 雏鹰可报名；线上进度 ≥99% 或线下结束 24h 内可提交心得申请并被审批入账  
- 类型二可按模板申请并审批入账  
- 后台八类权限包可配置；无权限不可操作  
- 演示一键三角色可用
