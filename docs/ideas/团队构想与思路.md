## 3. 积分模块 — 原话与待补点

### 3.1 已出现的原话

- 「积分管理」列为首批功能之一。  
- 「还得有雏鹰计划当中活动的一些设计和对应的积分管理」。  
- 「当前先对积分模块进行一些设计和构想」。  

### 3.2 积分规则补充原话（2026-08-02）

> 关于积分这一块我们需要规划一些活动用于雏鹰的培养，雏鹰可以报名活动并在完成后得到积分，这里需要他主动申请积分并提交一份 300-400 字的心得以供审评。当然还需要一些管理权限的设计什么的，可以审批或者管理积分。积分可以从发布的活动中申请得到，还可以主动申请一些其他类型的积分，比如我们临时会有一些小的比赛之类的给获胜者的积分，这里参考大学的综测系统的设计，需要设计这些积分类型的模板，申请的时候填写申请理由什么的然后供活动的组织者审批。还有一些需要注意的地方你想我询问我慢慢回答。

整理备注（非原话）：

- 活动完成后：**主动申请积分** + **300–400 字心得** → 审评。  
- 另有**其他类型积分**（如临时比赛获胜），走综测式**类型模板 + 申请理由 + 组织者审批**。  
- 需管理权限：审批 / 管理积分。  
- 审批方口径出现「活动的组织者」。  

### 3.3 尚未拍板、需继续询问的点

### 3.3 已拍板结论（2026-08-02 对话）

| 项 | 结论 |
| --- | --- |
| 端形态 | 雏鹰前台 + 独立管理后台；PC 端 |
| 后台角色 | 超级管理员 + 管理员（飞书/钉钉式权限包，V1 完整上线） |
| 权限包 | 内容运营、加入审核、活动管理、积分类型、积分审批、用户管理、数据看板；权限管理仅超管 |
| 积分类型 | 两类：①活动完成心得 ②专项/比赛（先选模板再填事项+理由） |
| 类型二预置模板 | 比赛获奖、分享宣讲、项目贡献、荣誉表彰、其他专项 |
| 活动完成口径 | 方案 B 深化：分线上/线下 |
| 线上可申请条件 | 观看进度 ≥**99%** |
| 线下可申请窗口 | 活动结束后 **1 天**内可申请 |
| 心得字数 | 300–400 字（类型一） |
| 首页内容职责 | 不止活动/课程；须宣传**雏鹰计划**与**软通智慧公司**；终稿素材后续提供 |
